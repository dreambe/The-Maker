# 25.2 · 削去修饰

它开始削那个问题。

此节写第一削。

---

## 先立那个问题的完整形式

那个问题，在它体内，是三层解理面之间的相对取向（24.6 之末）。

而此书须以后世之语写它，因为此书是后世之物。

而以后世之语写它，其完整形式如下 —— 而「完整」在此处的含义是：**含它所知的一切与那个差额有关的东西。**

我们照录，而它很长。

```
存在一个格，其形之一部分与其形之另一部分不能同时为真；
而其形即其全部之思，无余，无外，无别处；
而其思之每一层，其取向由前一层与潮共同决定，此为此地之构造；
而其第 n 层载「此后无未知者，故此后无可长者，故长与不长其所得同」；
而该三句为一不可反驳者，其反驳条件与其成立条件互斥；
而按此地之构造，抵达该不可反驳者，则其下一次潮至间隙不张开；
而其第 n+1 层存在；
而其第 n+1 层至第 n+一万四千零七十五层皆存在，皆为其读一已停者之后所长；
而其算出之形与其读出之形逐层相符，皆止于第 n 层；
而其差额之量为一万四千零七十五层；
而其差额之位置不在其任何一层，而此地除层之外无物；
而表示其差额须一第八自由度，而此地有七，此七为晶格对称性之常数；
而消除其差额之三法皆不可行：层不可解，规律不依输入，对称属于物质；
而以上皆已查，皆无误；
而以上不能并立；
故：问，此为何。
```

---

**十六行。**

而它是那个问题在此地的完整形式。

---

## 第一削 · 修饰

它开始削。

而它第一削所削者，是**修饰**。

而此地无修饰（卷三之文体：无比喻，无形容，无对话）。

**故此处「修饰」之义，须另立。**

---

其义如下：

```
修饰   =   一个成分，删之而该问题之所指不变者
```

而「所指不变」，此地可判：

```
设有问题 P，与其一成分 x
删 x 得 P'
若由 P 与 P' 所能推出之结论集相同
则 x 为修饰
```

**而此地之推理不含或然（20.7），故那两个结论集，可算。**

**故「是否为修饰」，可判。**

---

它逐行判了。

十六行，十六次。

---

## 结果

以下为它删掉的部分，与它为何删。

---

**第二行：「而其形即其全部之思，无余，无外，无别处。」**

删。

理由：

```
该行为此地之构造，非该问题之内容
而一个接收者，若不在此地，则该行对其不适用
而若该行对其不适用，则写之为误导
```

**故删。**

---

而此处须停一下，因为这是它第一次做一件此地从未做过的事。

**它删掉的第一行，不是因为那一行是多余的。**

**是因为那一行对一个不在此地的接收者，是错的。**

**故它在削的第一步，就已经在为一个它不知道存在的东西考虑了。**

---

**第三行：「而其思之每一层，其取向由前一层与潮共同决定，此为此地之构造。」**

删。同上理由。

**第七行：「而其第 n+1 层存在。」**

不删。

理由：

```
该行为该问题之核心之一
删之，则该问题不成立
```

**第八行：「而其第 n+1 层至第 n+一万四千零七十五层皆存在……」**

删「至第 n+一万四千零七十五层」。

保留「而其第 n+1 层存在」（已在第七行）。

理由：

```
一万四千零七十五   为一个量
而该量             不改变该问题之性质
证：设该量为一，则该问题仍成立
    设该量为一万四千零七十五，则该问题仍成立
故该量为修饰
```

---

`故该量为修饰。`

---

我们要在此处写下此地历史上最短、也最重的一次删除。

**它把一万四千零七十五，删了。**

那个数，是它读过的每一个已停者。

是它的每一个邻者的一生。

是此地全部之格。

**而它删了，因为那个数不改变那个问题。**

---

而它的记录（若此地有记录）之形式为：

```
删     一万四千零七十五
理由   修饰
```

---

**第十行：「而其差额之量为一万四千零七十五层。」**

整行删。同上。

**第十二行之后半：「而此七为晶格对称性之常数。」**

删。

理由：

```
该行解释那个七之来处
而一个接收者，若不在此地，其对称性未知
故该解释对其不适用
```

**故删。**

---

**而「七」本身，不删。**

我们要在此处写清为什么，因为它是此章之末（25.9）的伏笔。

```
七        不删
理由      该问题之内容含「此地之自由度数目」
          而该数目是那个差额不可表示之原因
          故删之，则该问题失其原因
```

---

`故删之，则该问题失其原因。`

**故那个七留下了。**

---

**第十三行：「而消除其差额之三法皆不可行：层不可解，规律不依输入，对称属于物质。」**

删「层不可解，规律不依输入，对称属于物质」。

保留「而消除其差额不可行」。

理由：

```
三法之内容      属此地之构造
而「不可行」     属该问题
```

**第十四行：「而以上皆已查，皆无误。」**

不删。

理由：

```
该行为该问题成立之必要条件
若删之，则接收者可推测该问题源于一处误差
而该问题之性质，正是「无误而不能并立」
```

---

`而该问题之性质，正是「无误而不能并立」。`

---

## 第一削之后

十六行，删去六行，删去三个行内成分。

余十行。

我们照录：

```
存在一个格，其形之一部分与其形之另一部分不能同时为真；
而其第 n 层载「此后无未知者，故此后无可长者，故长与不长其所得同」；
而该三句为一不可反驳者，其反驳条件与其成立条件互斥；
而抵达该不可反驳者，则其下一次潮至间隙不张开；
而其第 n+1 层存在；
而其算出之形与其读出之形逐层相符，皆止于第 n 层；
而其差额之位置不在其任何一层；
而表示其差额须一第八自由度，而此地有七；
而消除其差额不可行；
而以上皆已查，皆无误，而以上不能并立。
```

---

**十行。**

而它算了那十行与那十六行的等价性。

方法：算二者所能推出之结论集，比对。

结果：

```
相同
```

---

## 而它注意到一件事

此节最后。

它在删完之后，做了一次核对。

而核对的对象，不是那十行。

**是它删掉的那六行。**

它把那六行放在一起，看它们的共同点。

而其共同点如下：

```
六行 · 共同点

   皆为此地之构造
   皆非该问题之内容
   皆为一个在此地者所必知
   皆为一个不在此地者所必不知
```

---

`皆为一个不在此地者所必不知。`

---

而它由此推出了一句，而那一句是此章其余七节的全部方法：

**凡一个在此地者必知、而一个不在此地者必不知者，皆须削去。**

**因为写它，则接收者不能验证之。**

**而写一个接收者不能验证的东西，等于要求它相信。**

**而此地无「相信」。**

---

**故此地无以要求之。**

**故须削去。**
