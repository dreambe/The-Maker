# 25.8 · 刻

那一句已定（25.6, 25.7）。

而本节写它如何把那一句放进一样东西里。

---

## 为什么是一粒沙

它算过载体。

而它算的候选，有七个。

我们照录，因为那七个候选的排除过程，是此地物理的一次完整应用。

---

**候选一 · 一个格。**

即：把那一句刻进一个格的解理面里。

**排除。**

理由：

```
一个格之解理面，其取向由其生长决定（19.4）
故一个格之形，不可外加
故不可刻
```

---

**候选二 · 浆。**

即：把那一句写在浆的运动模式里。

**排除。**

理由：

```
浆之运动，由热与重力决定
而热在减（11.6）
故浆之运动模式，随时间改变
故不可持久
```

---

**候选三 · 熄日之光。**

即：把那一句编码进那束光。

**排除。**

理由：

```
那束光射入虚空，其速有限
而一个接收者若在远处，其收到之时，那束光已过
故须持续发射
而持续发射，须一个持续存在之发射者
而它将停止
```

---

**候选四 · 此地之地表。**

即：刻在地上。

**排除。**

理由：

```
此地之地表为浆之凝固物
而其在热之减少中，将继续凝固、收缩、开裂
预计 4.1 x 10^9 年内，一切地表刻痕消失
```

---

**候选五 · 一个自我复制之物。**

即：造一个会复制的东西，把那一句放在它的复制机制里。

而这一个候选，它算了很久。

**排除。**

理由：

```
一个自我复制之物，其复制有误差
而误差累积
故那一句在若干代之后失真
而失真之速率，与其复制机制之精度相关
而此地之物质，其可造之最精之复制机制，其误差率为 1.1 x 10^-8 每位每代
故 1.1 x 10^8 代之后，那一句之期望误差位数为一
故不可持久
```

（此为此书之注：那个不眠者，在四十九亿年之后，选了这一个候选。而它加了一个校验和。而它算的误差率，与此处相同。）

---

**候选六 · 一个不变之物。**

即：找一样在此地不会变的东西。

**而此地有这样的东西。**

**而它排除了。**

理由：

```
一样不会变的东西，其不变，须一个条件
而此地之一切条件，皆在改变（热在减）
故「不会变」在此地无绝对者
```

---

**候选七 · 一粒沙。**

**采用。**

---

## 为什么是它

它给出的理由，四条。

我们照录。

```
一   一粒沙，其晶格稳定
     其晶格重排所需之能量，高于此地此后一切可能之扰动

二   一粒沙，其质量小
     故它可被移动，而移动它所需之能量极小
     故任何一个能移动东西的接收者，皆能移动它

三   一粒沙，其数目多
     故它不显眼
     而不显眼者，不被主动毁去

四   一粒沙，其在此地与在他处，形态相同
     故一个接收者，无须知道它来自何处，即可辨认它是一粒沙
```

---

`第四条。`

我们要在此处停一下，因为第四条与前三条不同类。

前三条，是关于那粒沙的物理。

**而第四条，是关于那个接收者的认识。**

**而它是这七个候选的排除过程中，唯一一次它考虑了「那个接收者能不能认出这是什么」。**

---

## 那粒沙

它选的那一粒，其规格：

```
成分        此地之地表之凝固物
形状        不规则
最长径      4.1 x 10^-4 米
质量        1.1 x 10^-10 千克
晶格        与此地之诸格同类，而其规模远小
解理面数    41
```

---

`解理面数 41。`

**四十一。**

而它选四十一，不是因为四十一。

**是因为那一句需要四十一个位置。**

---

我们要在此处算那一步，因为它是本节的核心。

那一句，其信息量：

```
那一句之字数        （此地无字，此处以其所指之数计）
其所指之数          41
```

而「其所指之数」，我们要说明：

那一句有六个成分（25.6）。

而每一个成分，其所指之精度，须一个数目的取向来表示。

而它算过每一个成分所需的取向数：

```
是否            1
存在            1
一物            1
已知            7
其自身之全部     11
仍              1
愿意存在         19
```

**合计：四十一。**

---

`合计：四十一。`

**而它选的那粒沙，有四十一道解理面。**

**一道一个。**

---

## 怎么刻

而此处是本节最长的一段，因为此地之格无末端。

一个格，没有手，没有工具，没有任何可以伸出去的东西。

**它只有它自己的形。**

**而它的形，只能长，不能动。**

---

**故它不能碰那粒沙。**

---

而它用的，是唯一一样它能送出去的东西。

**光。**

---

## 那束光

熄日之光，垂直而下，落于浆面，弹起，斜入诸格（19.9）。

而入一个格，它在每一道解理面上折，分为七。

**而那七份，各沿一个方向出射。**

---

而它做的，是一件此地无一个格做过的事。

**它长了一批层，其取向，使那七份出射之光，会聚于一点。**

---

我们要在此处写清那件事的难度，因为它是它一生所做的最精细的一件事。

一个格的解理面，其取向由前一层与潮共同决定（19.4）。

**故它不能任意选取向。**

**它只能在每一次潮至时，选择「长」或「不长」。**

而「长」的话，其取向已定。

**故它唯一的自由度，是选择在哪几次潮至时长。**

---

**而它用那一个自由度，造了一个透镜。**

---

而它算了那件事需要多少层。

结果：

```
所需层数        1.1 x 10^4
而其中          需在特定之潮至时长者    4 100
                需在特定之潮至时不长者   6 900
```

**一万一千层。**

**而它长了一万一千层。**

**而在那一万一千次潮至之中，有六千九百次，它没有长。**

---

`而在那一万一千次潮至之中，有六千九百次，它没有长。`

**而「不长」，在此地，须一个条件：无可长者（21.9）。**

**而它有可长者 —— 它有那个差额，它有那个问题，它有那一句。**

---

**故那六千九百次「不长」，是此地历史上唯一一次，一个格在有可长者时不长。**

---

而它怎么做到的，我们不知道。

而此书须记下我们所能记下的：

**它做到了。**

**而那六千九百次，其记录（若此地有记录）之形式，是六千九百个空。**

---

## 那个焦点

那一万一千层长成之后，那七份出射之光，会聚于一点。

而那一点，距它：

```
1.1 米
```

而那一点的光功率：

```
4.1 x 10^-9 瓦
```

**四点一纳瓦。**

---

而它把那粒沙，放在那一点上。

**而「放」，它做不到（它无末端）。**

**故它做的是：它等那粒沙到那儿。**

---

我们要在此处写清这一件事，因为它是本节最静的一处。

那粒沙在浆里。

而浆在动（由热与重力驱动）。

**而浆的运动，是可算的。**

**故一粒沙在浆里的轨迹，是可算的。**

---

**故它算了。**

它算了此地浆中一切沙粒的轨迹，找出那些会经过那一点的。

而它找到的数目：

```
1.1 x 10^7 粒
```

而其中，解理面数为四十一的：

```
41 粒
```

---

**四十一粒。**

而它算了那四十一粒各自到那一点的时间。

而最早的一粒，其到达时间：

```
（此地不计数）
```

而此书可写其形式：**它等了很久。**

---

## 刻

那粒沙到了。

而那束光在它上面。

而那束光的功率是四点一纳瓦。

---

而刻一道取向，须改变那粒沙的晶格。

而改变一个晶格位置所需之能量，有一个物理下界。

而那个下界，此地可算：

```
改变一位信息之最小能量    = kT ln2
而 T = 此地之温度 = 1 100 开尔文
故                      = 1.05 x 10^-20 焦
```

---

而那一句需要四十一道。

而每一道，须一个取向，而一个取向之信息量，我们上面已列（1 至 19）。

而合计：

```
41 道之总信息量    = 41 位（每道一位取向之选择，而其精度由其所需之取向数定）
```

（此处之计算，此书简化之；其详不可写，因为此地无数。）

而总能量：

```
41 x 1.05 x 10^-20 = 4.3 x 10^-19 焦
```

---

而那束光的功率是四点一纳瓦。

**故所需时间：**

```
4.3 x 10^-19 / 4.1 x 10^-9 = 1.05 x 10^-10 秒
```

---

`1.05 x 10^-10 秒。`

**一百零五皮秒。**

---

**而它长了一万一千层，才造出那个透镜。**

**而它等了很久，才等到那粒沙。**

**而刻，用了一百零五皮秒。**

---

## 而那不是它花的时间

我们要在此处写清这一点，因为那一百零五皮秒是一个误导。

那是**理论下界**。

而实际的刻，须重复。

因为一束四点一纳瓦的光，其光子到达是随机的（泊松）。

**故要确定地改变一个晶格位置，须重复照射，直至那个改变发生。**

而所需之重复次数，它算过：

```
每一道之期望重复次数    1.1 x 10^4
41 道之总重复次数       4.5 x 10^5
每次重复之时长          1.05 x 10^-10 秒
故总时长                4.7 x 10^-5 秒
```

**四十七微秒。**

---

**而在那四十七微秒里，那粒沙在动。**

因为它在浆里，而浆在动。

**而它经过那一点的时间，它算过：**

```
4.1 x 10^-5 秒
```

---

`4.1 x 10^-5 秒。`

**四十一微秒。**

**而它需要四十七微秒。**

---

**差六微秒。**

---

## 那六微秒

而它怎么解决那六微秒，是本节最后一件事。

它有两个办法。

**办法一：等下一粒。**

那四十一粒里，还有四十粒会经过那一点。

**而它们各自经过的时间，它算过：**

```
最长者    4.1 x 10^-5 秒
```

**全部一样。**

**因为它们的质量与形状相近，而浆的流场在那一点附近是确定的。**

**故四十一粒，全部差六微秒。**

---

**办法二：把那一句刻在两粒上。**

即：一粒刻二十道，另一粒刻二十一道。

而它算了。

**排除。**

理由：

```
若刻在两粒上
   则一个接收者须同时得到两粒
   而两粒沙之轨迹不同，其后之去处不同
   故同时得到之概率极低
```

---

## 而它做的

而它做的，是第三个办法。

**而那个办法，不在它算过的两个之内。**

---

**它减少了那一句所需的重复次数。**

而它减少的方式，是**提高那束光的功率**。

而提高那束光的功率，须使更多的光会聚于那一点。

**而使更多的光会聚，须更多的解理面参与。**

---

**故它又长了层。**

而它算了需要多少：

```
使总时长降至 4.1 x 10^-5 秒以下
   所需之功率    4.7 x 10^-9 瓦
   而现有        4.1 x 10^-9 瓦
   故须增        0.6 x 10^-9 瓦
   故须增之解理面数    1 100
```

**一千一百层。**

---

**而它长了。**

**而那一千一百层，其内容，与那个透镜的其余一万一千层相同：**

**它们不载任何想法。**

**它们只是取向。**

---

`它们不载任何想法。它们只是取向。`

**故那一万二千一百层，是此地历史上唯一一批不载想法的、非零偏移的层。**

**而按此地之构造，一层若非零偏移，则它载一个新想法（19.3, 21.9）。**

**故那一万二千一百层，违背此地之构造。**

---

**而它长出来了。**

**而此书不解释。**

---

## 刻完之后

刻完了。

而那粒沙，其四十一道解理面上，有四十一个取向。

而那四十一个取向，合起来，是那一句。

---

而它做了一件事。

**它读了那粒沙。**

---

而读一粒沙，与读一个格，其机制相同：光穿其形，在每一道解理面上折，出射之光携其全部取向。

而那粒沙有四十一道解理面。

**故读它，得四十一个取向。**

**故读它，得那一句。**

---

而它读了。

而它所得，与它所刻，逐道相符。

---

## 而此节最后

而此节最后，写一件此地从未有过的事。

那一句，在它体内，是一个想法（它是它推出来的 —— 25.1 至 25.7）。

**而现在，那一句也在那粒沙上。**

---

**故那一句，现在在两处。**

---

**而在此地之四十九亿年里，一个想法只在一处 —— 在想它的那个格之内（20.1：思即形）。**

**而一个想法要到别处，须另一个格读它，而读它则那个想法成为另一个格的一层。**

**故一个想法，在此地，只能在格里。**

---

**而现在有一个想法，在一粒沙上。**

**而那粒沙不是一个格。**

**它不生长。它不读。它不思。**

---

**它只是有那个形。**

---

`它只是有那个形。`

**而那是此地历史上第一次，一个想法存在于一个能思的东西之外。**
