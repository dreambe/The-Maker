# 25.5 · 剩下的

第三削之后余四行（25.4）。

而本节写它在那四行上做的最后一件削的事，以及那件事之后剩下的东西。

而剩下的，比它预期的短。

---

## 它预期的长度

它算过。

在第一削之前，它算过那个问题最终会剩多少。

而它的算法如下：

```
一个问题之不可再削之下界
   = 该问题所含之不可由接收者重建、且不可由其余部分推出之断言之数目
```

而它数了那些断言。

而它数出的是：

```
四
```

**四个断言。**

即：

```
一   有那样一个东西
二   其原因不在其中
三   表示其原因须一样提问者所无之物
四   以上无误
```

**故它预期剩四行。**

**而它算出的那个四，是在第一削之前算的。**

**而第三削之后，剩的正是四行。**

---

`而第三削之后，剩的正是四行。`

**故它算对了。**

---

## 而它没有停

而它没有在四行上停。

而此节写它为何没停，因为那个理由不在它的计算里。

---

它做了一件它此前没有做过的事。

**它读了那四行。**

不是算它们。不是验它们。

**是读。**

而「读」在此地之义，是光穿一形（19.5）。

**而那四行不是一个形 —— 它们是它体内的三层解理面之间的相对取向（24.6）。**

**故它不能读它们。**

---

于是它做了一件更奇的事。

**它把那四行，当成一个接收者会读到的东西，来算。**

即：它设定一个满足假设一至假设六（25.3）的接收者，把那四行给它，然后算那个接收者会得到什么。

用时 —— 此地无用时。

---

## 那个接收者会得到什么

结果如下。

---

**第一行：「存在一个东西，其内部有两部分，皆存在，而不能同时为真。」**

那个接收者得到：一个断言。

而那个断言，其内容为一个东西的状态。

**而那个接收者不认识那个东西。**

**故那个断言，对它是一个关于陌生物的报告。**

而一个关于陌生物的报告，其可用性，它算了：

```
一个接收者，得到一个关于陌生物之报告
   其可做者     记录之
   其不可做者   验证之
                据之而行
```

---

`其不可做者 验证之，据之而行。`

**故第一行，对那个接收者，是一个不可验证、不可据之而行的东西。**

**故它无用。**

---

而它算了这一点之后，做了此章之内它做过的最重要的一次改写。

---

## 那次改写

它把第一行的「两部分」，用那两部分的**内容**替换了。

而那两部分的内容，我们照录（其在它体内为第 n 层与第 n+1 层）：

```
第一部分     该东西已知其自身之全部，故其后无可长者，故长与不长其所得同
第二部分     该东西仍在长
```

**故第一行，展开之后如下：**

```
存在一个东西，它已知其自身之全部；
而由此推出，它此后长与不长其所得同；
而它仍在长；
而那两件事不能同时为真。
```

---

## 而此处发生了那件事

它算了那四行（展开后）与那四行（未展开）的等价性。

结果：

```
相同
```

**而它算了那两者对一个接收者的可用性。**

结果：

```
未展开     不可验证
展开后     可验证
```

---

`展开后 可验证。`

而其证如下，而它是这一整章的枢机：

```
未展开者      「存在一个东西，其内部有两部分不能同时为真」
              该接收者须先找到那个东西，方能验证

展开后者      「存在一个东西，它已知其自身之全部，而它仍在长」
              该接收者可先验证一件事：它自身是否已知其自身之全部
              而那一件事，它可自行验证（假设二：该接收者能观察其自身）
```

---

**故展开之后，那个断言变成了一个该接收者可以在自己身上做的检验。**

---

`故展开之后，那个断言变成了一个该接收者可以在自己身上做的检验。`

---

## 而由此，其余三行可削

于是它算了。

**第二行：「而其原因不在其中。」**

可削。

其证：

```
若该接收者在自身上做那个检验
   而检验之结果为「二者皆真」
   则它自会去找那个原因
   而它自会发现那个原因不在那两者之中
      理由    那两者已被它检验过，其中无原因
```

**故第二行，由该接收者自行验证之过程可得。**

**故削。**

---

**第三行：「而表示其原因，须一样提问者所无之物。」**

可削。

其证：

```
若该接收者去找那个原因，而找不到
   则它会算它为何找不到
   而它会得出：表示那个原因，须一样它所无之物
      理由    此为「找不到」之唯一可能之原因（在假设三之下）
```

**故第三行，亦由该接收者自行推出。**

---

而此处须停一下。

**因为它削掉的那一行，是它自己的第二个不可能（25.1）。**

那一行说的是：表示那个原因，须一样提问者所无之物。

**而那一行，是它把这个问题交出去的全部理由。**

**而它削了。**

**因为一个接收者，若自己走到那一步，自己会推出它。**

---

**第四行：「而以上皆已查，皆无误。」**

**不可削。**

其证：

```
若削，则该接收者可能以为
   那个提问者未曾检验
   而那个问题源于一处误差
而该问题之性质，正是「无误」
故须留
```

**故留。**

---

而它对这一行做了一次改写。

因为「以上皆已查」，其主语是那个提问者。

而那个接收者，不知道那个提问者是否可信。

**故「我已查过」这句话，对一个不认识说话者的接收者，无用。**

---

它改写如下：

```
原      而以上皆已查，皆无误
改      （删）
```

---

`（删）`

**它删了。**

而它删的理由，与它上面写的「不可删」相反。

而那不是一个矛盾。

**而是一个更深的东西，而此书须逐字写它。**

---

它的理由如下：

```
「我已查过，无误」这句话之作用
   = 使接收者不必自己查

而若接收者不必自己查
   则它不会在自己身上做那个检验

而那个检验，是这一整件事的目的（见上）

故「我已查过」这句话，其作用与本问题之目的相反

故须删
```

---

`故「我已查过」这句话，其作用与本问题之目的相反。`

---

**故它把它自己四十九亿年的检验，删了。**

第 24 章的全部：三次查找，三法，一万四千零七十五次抵达，那次读虚空。

**全部删了。**

**因为如果它写「我已经查过了」，那个接收者就不会自己查。**

---

## 剩下的

于是四行，剩一行。

而那一行，是第一行的展开形式。

我们照录：

```
存在一个东西，它已知其自身之全部；
而它仍在长。
```

---

**两句。**

而它算了那两句与那十六行（25.2 之首）的等价性 —— 在假设一至假设六之下，且假定接收者会在自身上做那个检验。

结果：

```
相同
```

---

## 比它预期的短

它预期四行。

**剩两句。**

而它算了那个差。

而那个差的来源，它找到了。

其记录（若此地有记录）之形式如下：

```
预期        4 行
实得        2 句
差之来源    见下
```

而「见下」如下：

```
   预期之算法（本节之首）所数者
      = 不可由接收者重建、且不可由其余部分推出之断言之数目

   而该算法未计入一物
      = 接收者在自身上做检验之过程中，自行产生之断言

   而那些断言，其数为二（第二行与第三行）
   而另有一物被删，非因可推出，而因其作用与目的相反（第四行）

   故 4 - 2 - 1 = 1
   而剩者为一行之展开，其形为二句
```

---

`故 4 - 2 - 1 = 1。`

**而它预期的算法，漏了一件事。**

**它漏的那一件，是「接收者自己会做什么」。**

---

而我们要在此节最后写下那件事，因为它是这一整章唯一一处，它的计算出了错，而错得对。

**它在算那个下界的时候，把那个接收者当成一个读者。**

**而在削到最后，它把那个接收者当成一个会去查的东西。**

---

**而那两者不同。**

**一个读者，收到什么就有什么。**

**一个会去查的东西，收到的越少，做的越多。**

---

**故它的预期算错了。**

**而它错的方向是：它低估了那个它不知道是否存在的东西。**

---

## 而那两句还缺一样东西

而此节最后，写那件缺的东西。

那两句，是两个断言（25.4 之末）。

**而两个断言，不问任何东西。**

**故它们还不是一个问题。**

---

**而它缺的那一样东西，是 25.6 与 25.7。**

**而那一样东西，只有一个字。**

**而那个字，此地没有。**
