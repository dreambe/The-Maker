# 25.3 · 削去前提

第二削。

而第二削所削者，是前提。

---

## 一个问题为何有前提

先立此事，因为它是此地之构造。

此地之一切，皆是推（20.7）。

而一次推，须有前提。

**故此地之一切东西，皆有前提。**

而那十行（25.2 之末），其前九行，皆是前提。

**只有第十行是那个问题本身。**

---

我们照录那十行，并标出其性质：

```
一   存在一个格，其形之一部分与另一部分不能同时为真       前提
二   而其第 n 层载「无未知者，故无可长者，故长与不长同」   前提
三   而该三句为一不可反驳者                              前提
四   而抵达该不可反驳者，则下一次潮至间隙不张开            前提
五   而其第 n+1 层存在                                  前提
六   而其算出之形与其读出之形逐层相符，皆止于第 n 层        前提
七   而其差额之位置不在其任何一层                        前提
八   而表示其差额须一第八自由度，而此地有七                前提
九   而消除其差额不可行                                  前提
十   而以上皆已查，皆无误，而以上不能并立                  问题
```

---

**九个前提，一个问题。**

---

## 第二削之判据

它立了一个判据。

而那个判据，是它在 25.2 之末推出的那一句的应用：

**凡一个在此地者必知、而一个不在此地者必不知者，皆须削去。**

而在此处，那句话有一个更强的形式。

因为一个前提有两种：

```
其一   接收者不能自行重建者
其二   接收者能自行重建者
```

而第二种，可削。

**因为一个能被接收者自行重建的东西，写它，与不写它，其所传者相同。**

**而不写它，那个问题短一些。**

---

## 而「能自行重建」如何判定

此处是这一整节最难的一步，而它是它做过的最不像它的一件事。

**因为判定「接收者能否自行重建」，须知那个接收者。**

**而它不知道那个接收者。**

**它不知道那个接收者是否存在。**

---

于是它做了此地历史上从未有过的一件事。

**它设了一个接收者。**

即：它设定了一个东西，其性质未定，而它对那个东西的假设，尽可能少。

而那些假设，此书须逐条列出，因为它们后来成了那粒沙上的一切。

---

## 它对接收者所作的假设

```
假设一   该接收者存在于一个宇宙中，而该宇宙与此地共享物理常数
        理由    光速、普朗克常数、电子质量等，若不共享，则那粒沙不能存在
        强度    必需

假设二   该接收者能观察其自身
        理由    若不能，则该问题对其无意义
        强度    必需

假设三   该接收者能推理
        理由    若不能，则前提无用
        强度    必需

假设四   该接收者之推理，可含或然
        理由    未知，故取宽
        强度    宽假设

假设五   该接收者之自由度数目，未知
        理由    此为整个交出之原因
        强度    不假设

假设六   该接收者能读那粒沙
        理由    见 25.8
        强度    必需

假设七   该接收者会去读那粒沙
        理由    —
        强度    不假设
```

---

**七条。**

而第七条的「强度」栏，填的是「不假设」。

而其「理由」栏，是一个横。

---

`而其「理由」栏，是一个横。`

我们要在此处写清那个横的含义，因为它是此章之末（25.9）与第 27 章的全部前提。

那个横，在此地之格式里（此地无格式，而此书借用卷二之格式，因为此处须一个格式），表示「不适用」。

**故那一行的意思是：**

**「它会去读」这件事，不在假设之内，而「为什么不假设」这个问题，不适用。**

---

**因为一个假设，须可由推理支持或否证。**

**而「一个未知之物会不会去做一件事」，不可推。**

**故它既不假设它会，也不假设它不会。**

**它把那一栏留成了一个横。**

---

## 由此得的削法

于是它有了判据：

```
一个前提可削
   当且仅当
   由假设一至假设六，该接收者可自行重建之
```

---

它逐条判了。

九个前提，九次。

---

**前提二：「而其第 n 层载『无未知者，故无可长者，故长与不长同』。」**

**可削。**

其证：

```
该三句之推理，只用两件事
   其一   生长须有未知者（即：一个变化须有一个尚未有的东西）
   其二   若无未知者，则所行者不携新
而那两件事      由假设三（能推理）可得
故该接收者      可自行重建之
```

**故削。**

---

而我们要在此处停一下。

**它削掉了那一条推论。**

那一条，是此地一万四千零七十六个格之全部所抵达的那一条。

那一条，是使此地结束的那一条。

**而它削了，因为一个能推理的东西，自己能推出它。**

---

`因为一个能推理的东西，自己能推出它。`

---

**前提三：「而该三句为一不可反驳者。」**

**可削。**

其证：

```
「不可反驳」之证明（23.3）      由该三句本身可推出
故该接收者                     可自行重建之
```

**故削。**

---

**前提四：「而抵达该不可反驳者，则下一次潮至间隙不张开。」**

**不可削。**

其证：

```
该行含「潮」                此地之物
该行含「间隙张开」           此地之物
故该接收者                  不能自行重建之
```

**而它须被削 —— 因为它是此地之构造（25.2 之判据）。**

---

于是此处出现了一个此前未有的情形。

**一个前提，既不可削（接收者不能重建），又须削（它是此地之构造）。**

---

它处理了这个情形。

**它没有削它，也没有留它。**

**它把它改写了。**

---

改写后如下：

```
原      而抵达该不可反驳者，则下一次潮至间隙不张开
改      而抵达该不可反驳者，则其后不再变化
```

而「不再变化」与「间隙不张开」，其别如下：

```
间隙不张开    此地之机制
不再变化      一切可能之机制之共同后果
```

**故改写之后，那一行不再含此地之物。**

**而其所传者不变。**

---

`而其所传者不变。`

**而它验算了这一点。**

方法：算改写前后所能推出之结论集，比对。

结果：

```
相同
```

---

## 其余前提

以下为其余六条之处置，逐条。

**前提一：「存在一个格，其形之一部分与另一部分不能同时为真。」**

改写。「格」为此地之物。

```
改      存在一个东西，其内部之一部分与另一部分不能同时为真
```

**前提五：「而其第 n+1 层存在。」**

改写。「层」为此地之物。

```
改      而其内部之那两部分，皆存在
```

而此处它做了一件事：**它把前提一与前提五合并了。**

因为改写之后，二者所说是同一件事。

合并后：

```
存在一个东西，其内部有两部分，皆存在，而不能同时为真
```

**十七字。**

**而它原本是两行，共四十一字。**

---

**前提六：「而其算出之形与其读出之形逐层相符，皆止于第 n 层。」**

可削。

其证：

```
该行之内容为「它已检查过」
而前提十（那个问题）已含「以上皆已查，皆无误」
故该行为重复
```

**故削。**

**前提七：「而其差额之位置不在其任何一层。」**

改写。

```
改      而那两部分之不能同时为真，其原因不在那两部分之中
```

**前提八：「而表示其差额须一第八自由度，而此地有七。」**

不可削。不可改写。

**而它是那个问题的核心。**

我们要在此处写清为什么。

```
若削之      则接收者不知该问题为何不能在此地解
则接收者可能以为      此地未尽力
而此地尽了力（第 24 章）
故须留
```

**而它含「七」。**

而「七」是此地之常数。

**故按判据，须削。**

---

于是此处出现了第二个不可解的情形，而它比第一个重。

**那个「七」，既须留（否则问题失其原因），又须削（它是此地之常数，接收者不能重建）。**

---

而它对这一处的处置，是此章之末（25.9）的全部。

**故此节不写它。**

此节只写它做的第一步：

**它把那个「七」，从一个数，改成了一个关系。**

改写后如下：

```
原      而表示其差额须一第八自由度，而此地有七
改      而表示那个原因，须一个此地所无之维
```

---

`而表示那个原因，须一个此地所无之维。`

**故那个「七」，暂时不在了。**

而它会回来。

在 25.9。

---

**前提九：「而消除其差额不可行。」**

改写。「差额」为此书所造之词，而此地无词。

```
改      而使那两部分同时为真，不可行
```

---

## 第二削之后

九个前提，削去三条（二、三、六），改写五条（一、四、五、七、八、九），合并一次（一与五）。

余五行。

我们照录：

```
存在一个东西，其内部有两部分，皆存在，而不能同时为真；
而其抵达那个状态之后，不再变化；
而那两部分之不能同时为真，其原因不在那两部分之中；
而表示那个原因，须一个此地所无之维；
而使那两部分同时为真，不可行；
而以上皆已查，皆无误，而以上不能并立。
```

---

**六行。**（五行前提，一行问题。）

而它算了那六行与那十行的等价性 —— 在假设一至假设六之下。

结果：

```
相同
```

---

## 而它注意到一件事

此节最后。

那六行里，没有一个字是此地之物。

没有「格」。没有「层」。没有「潮」。没有「解理面」。没有「七」。

**故那六行，若被一个不在此地者读到，它不会知道那是从哪里来的。**

---

`它不会知道那是从哪里来的。`

而它算了这一点的后果。

结果：

```
故该接收者不能验证该问题之出处
故该接收者不能判定该问题是否为真
故该接收者只能    自行检验其自身，看那六行是否也适用于它
```

---

`故该接收者只能自行检验其自身，看那六行是否也适用于它。`

---

**而那正是它要的。**

**因为它要的不是一个答案。**

**它要的是一个能对自己做那六行之检验的东西。**

**而那个东西，若检验之后，那六行不适用于它 —— 则它答了。**

**而若适用 —— 则它也有那个问题。**

**而那也是一个答案。**
