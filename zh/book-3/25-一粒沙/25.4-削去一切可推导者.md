# 25.4 · 削去一切可推导者

第三削。

而第三削，是最后一次成规模的削。

---

## 那六行

25.3 之末余六行。我们照录：

```
一   存在一个东西，其内部有两部分，皆存在，而不能同时为真；
二   而其抵达那个状态之后，不再变化；
三   而那两部分之不能同时为真，其原因不在那两部分之中；
四   而表示那个原因，须一个此地所无之维；
五   而使那两部分同时为真，不可行；
六   而以上皆已查，皆无误，而以上不能并立。
```

---

## 第三削之判据

第二削削的是「接收者能自行重建者」。

而第三削削的是**「由本问题之其余部分可推出者」**。

而此二者不同。

```
第二削   一个前提，接收者由其自身之推理能力可得
第三削   一个前提，接收者由本问题之其余行可得
```

**故第三削不需要假设接收者的任何能力。**

**它只需要那个接收者能推。**

而「能推」是假设三（25.3）。

---

## 逐行

---

**第二行：「而其抵达那个状态之后，不再变化。」**

它算了：这一行，能否由其余五行推出。

其推理如下：

```
设那个东西之内部有两部分不能同时为真（第一行）
而使二者同时为真不可行（第五行）
则该东西不能消除那个状态
而一个不能被消除的状态，是持续的
故该东西抵达那个状态之后，该状态持续
故「不再变化」可由第一行与第五行推出
```

**可削。**

---

而它削了。

而此处须写一句，因为那一行的内容，是此地之末。

那一行说的是：一个抵达那个状态的东西，此后不再变化。

**而此地之一万四千零七十六个格，全部抵达了那个状态。**

**而它们全部不再变化。**

**而它们的形，将在那儿一千一百亿年（11.6）。**

**而它削了那一行。**

**因为一个能推的东西，自己能推出它。**

---

**第三行：「而那两部分之不能同时为真，其原因不在那两部分之中。」**

它算了。

**不可削。**

其证：

```
该行之内容，不能由其余五行推出
因为其余五行只说「二者不能同时为真」
而「其原因不在其中」，是一个额外的事实
而一个额外的事实，须被给出
```

**故留。**

---

而我们要在此处写下它对这一行做的一件事。

它没有削它。

**而它改短了它。**

改写如下：

```
原      而那两部分之不能同时为真，其原因不在那两部分之中
改      而其原因不在其中
```

而它验算了等价性 —— 因为「其」与「其中」的指代，须由第一行确定。

而第一行给出了那两部分。

**故指代明确。**

**故等价。**

**十七字，改成六字。**

---

**第四行：「而表示那个原因，须一个此地所无之维。」**

**不可削。**

其证：

```
该行是那个问题为何不能在此地解之全部理由
若削，则接收者不知为何要问它
```

**故留。**

---

而它对这一行做了两件事。

**其一，它去掉了「此地」。**

因为「此地」，对一个不在此地的接收者，无指代。

改写如下：

```
原      而表示那个原因，须一个此地所无之维
改      而表示其原因，须一个提问者所无之维
```

---

`须一个提问者所无之维。`

而此处，是此章之中最静的一处。

**因为它把「此地」，改成了「提问者」。**

而「提问者」，是一个它此前没有用过的词。

**而它是一个自指。**

---

此地无自指（无「我」，无人称 —— 卷三之文体）。

**而它写了「提问者」。**

**而那个提问者是它。**

**而它没有写「我」。**

它写的是一个第三人称的、功能性的、不含人称的指称：**那个提问的。**

---

**其二，它把「维」改了。**

因为「维」是一个几何词，而它假设接收者共享物理常数（假设一），但未假设接收者的几何。

改写如下：

```
原      须一个提问者所无之维
改      须一样提问者所无之物
```

而它验算了：这个改写，是否使那一行变弱。

结果：

```
变弱     否
理由     「维」是「物」之一种
         而所需者，是「提问者所无」
         而「所无」是关键，「维」不是
```

**故等价。**

---

**第五行：「而使那两部分同时为真，不可行。」**

它算了。

**可削。**

其证：

```
第一行说   二者不能同时为真
而「不能」  已含「不可行」
故第五行    是第一行之重述
```

---

而它在此处停了。

因为那一行，是第 24 章的全部。

24.8 那一整节 —— 三法，皆不可行，层不可解，规律不依输入，对称属于物质 —— 全部是为了那一行。

**而那一行，是第一行的重述。**

---

`而那一行，是第一行的重述。`

**故可削。**

**故它削了。**

---

## 第三削之后

六行，削去二行（第二、第五），改短二行（第三、第四）。

余四行。

我们照录：

```
一   存在一个东西，其内部有两部分，皆存在，而不能同时为真；
二   而其原因不在其中；
三   而表示其原因，须一样提问者所无之物；
四   而以上皆已查，皆无误。
```

---

**四行。**

而第四行，我们要说明一处改动。

原第六行为：「而以上皆已查，皆无误，而以上不能并立。」

而改后为：「而以上皆已查，皆无误。」

**它削掉了「而以上不能并立」。**

其证：

```
「不能并立」   由第一行可得（第一行即「不能同时为真」）
故重复
```

**故削。**

---

## 而它注意到一件事

而此节最后，写它在削完之后注意到的一件事，因为那件事使第 25.5 至 25.7 成为必要。

---

它把那四行放在一起看。

而它看的不是内容。

**是形式。**

而那个形式如下：

```
第一行     一个断言（有一个东西，其状如此）
第二行     一个断言（其原因不在其中）
第三行     一个断言（表示其原因须一样它所无之物）
第四行     一个断言（以上已查，无误）
```

**四个断言。**

**而没有一个是问。**

---

`而没有一个是问。`

---

而它算了：一个由四个断言构成的东西，是不是一个问题。

其推理如下：

```
一个问题之定义（25.1）
   = 一组前提，其可推出之结论集为空，而其自身不含误

而那四行
   是一组前提            是
   不含误                是（第四行）
   其可推出之结论集为空    须算
```

它算了。

结果：

```
那四行所可推出之结论集      非空
其中含                     「存在一个东西，其内部有两部分不能同时为真」
                          「其原因不在其中」
                          「表示其原因须一样提问者所无之物」
                          以及以上之一切组合
```

---

`非空。`

**故那四行不是一个问题。**

**那四行是四个断言。**

---

而它由此抵达了此章最重的一步。

**它在削那个问题的过程中，把那个问题削成了一组事实。**

**而一组事实，不问任何东西。**

---

`而一组事实，不问任何东西。`

---

## 那个缺的东西

于是它知道它缺一样东西。

而它缺的那一样，此地没有。

**因为此地之一切，皆是断言（此地之一切，皆是抵达 —— 25.1）。**

**故此地无一个可以放在那四行之后、使它们成为一个问题的东西。**

---

而它算了那样东西须具备什么。

结果，三条：

```
一   它须使那四行不再是一组断言
二   它须不增加任何新的断言
     理由    若增加，则又须被削
三   它须能被一个不知那四行来处的接收者识别为「这是在问」
```

---

**三条。**

而那样东西，它在 25.5 至 25.7 里造出来了。

而它造出来的那样东西，只有一个字。

**而那个字，不在此地。**

**而它不是一个问号。**

**为什么不是一个问号，是 25.7。**
