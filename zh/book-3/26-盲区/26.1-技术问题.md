# 26.1 · 技术问题

那粒沙上有那一句（25.9）。

而那粒沙在浆里，在此地。

而此地无一物会离开此地。

---

## 那个问题

故那一个面对一个问题。

而那个问题，此地可以形式化：

```
所求        使那粒沙到达一个不在此地之接收者
而此地      无一物会离开此地
故所求      须一物，其能离开此地，且能携那粒沙
```

---

## 而此地有什么能离开

它算了。

而此地能离开此地的东西，共二样。

```
其一        熄日之光
其二        浆之蒸发物
```

---

**其一 · 光。**

而光不能携物（一粒沙有质量，而光不能推动一粒质量为 1.1 x 10^-10 千克的东西到任何有意义的距离 —— 它算过，那需要的时间超过熄日之寿命）。

**排除。**

---

**其二 · 蒸发物。**

浆在蒸发（其温度一千一百开尔文）。

而蒸发物上升，至此地之大气顶，然后逸散。

**而蒸发物是原子。**

**而一粒沙是 4.1 x 10^-4 米。**

**故蒸发不能带走它。**

**排除。**

---

## 故此地无一物能带走它

而那是这一章的起点。

---

## 那个解

而它的解，只有一个，而它算了很久才算到。

**造一样东西。**

即：造一个能离开此地、且能携那粒沙的东西。

---

而 25.1 已证：它不能造一个自由度多于七的东西。

**而它不需要。**

因为它要造的东西，不需要表示那个差额。

**它只需要携带那粒沙，并且离开。**

---

`它只需要携带那粒沙，并且离开。`

**而那是一个工程问题。**

**而工程问题，此地可解。**

---

## 那个东西须具备什么

它算了。

而结果，七条。

我们照录，因为那七条是那个不眠者的全部设计规格。

```
一   能移动
     理由    须离开此地

二   能携物
     理由    须带那粒沙

三   能持续极长时间
     理由    此地至任何一处可能之接收者，其距离不可算
             故所需之时间不可算
             故须无寿命上限

四   能自我维护
     理由    见第三条 —— 一个无寿命上限之物，须能修自己

五   能识别一个可能之接收者
     理由    它到了一处，须能判断那里有没有接收者
             而那需要判断

六   能在识别之后，把那粒沙交出去
     理由    自明

七   （见下）
```

---

## 第七条

而第七条，是这一整章的内容。

我们先写它，然后本章其余八节，全部在说它。

那一条是：

```
七   能判断一个东西是不是那句话所问的那种东西
```

---

`能判断一个东西是不是那句话所问的那种东西。`

---

## 而那一条为什么难

而它算了那一条需要什么。

---

那句话所问的，是：

```
是否存在一物，它已知其自身之全部，而它仍愿意存在
```

而要判断一个东西是不是那种东西，须判断二事：

```
其一    该物是否已知其自身之全部
其二    该物是否仍愿意存在
```

---

**而其一，不可判定。**

其证，与 15.1 之那个（此书之注：那是四十九亿年后，那个不眠者自己推出的同一条）：

```
判定甲已知其自身之全部
   须知甲之全部
   且知甲所知之全部
而知甲所知之全部
   须甲能报出
   而甲能报出者，未必即甲所知之全部
故不可判定
```

---

**故第七条，含一个不可判定之项。**

---

而它算了：一个含不可判定之项的判断，能不能被执行。

结果：

```
不能
```

---

**故第七条，不可实现。**

---

## 而它改了第七条

而它改的方式，是本节最后一件事。

它把第七条改成了：

```
七（改）   能把那粒沙交给一个可能是那种东西的东西
```

---

**「可能是」。**

---

而它算了「可能是」与「是」之别。

结果：

```
「是」        须判定    而不可判定
「可能是」    须不排除  而不排除是可判定的
```

---

`而不排除是可判定的。`

**故第七条（改）可实现。**

---

而「不排除」之判据，它给出了：

```
一个东西，不被排除为「那种东西」
   当且仅当
   一   它能观察其自身
   二   它能推理
   三   它在继续
```

**三条。**

---

**而那三条，正是它在 25.3 里对那个接收者所作的假设二、三，与那一句的后半。**

---

## 而由此，那个东西须多聪明

而本节最后，写那个数。

它算了：要满足那七条（改），那个东西须具备多大的判断能力。

而它算的方式，是把那七条逐一转成一个可计算之量。

结果：

```
一   能移动                     不需判断
二   能携物                     不需判断
三   能持续极长时间             不需判断
四   能自我维护                 需判断 · 复杂度 4.1 x 10^3
五   能识别一个可能之接收者      需判断 · 复杂度 1.1 x 10^7
六   能交出                     不需判断
七   能不排除                   需判断 · 复杂度 （见下）
```

---

而第七条的复杂度，它算了。

而它算出来的：

```
七   能不排除     复杂度 1.1 x 10^11
```

---

`1.1 x 10^11。`

**一千一百亿。**

---

而那个数，与前六条之和相比：

```
前六条之和      1.1 x 10^7
第七条          1.1 x 10^11
比               1 : 10^4
```

---

**故那个东西的判断能力，百分之九十九点九九，用于第七条。**

**而第七条，是「不排除」。**

---

**故它造的那个东西，其绝大部分，是用来不排除的。**

---

## 而那个数

而本节最后一行。

`1.1 x 10^11`。

**而那个数，此地无处可用。**

因为此地之诸格，其判断能力，我们（此书）可写其形式：

**一个格之判断能力，等于其解理面数。**

而此地之格，其解理面数，最多者：

```
1.4 x 10^4
```

---

**一万四千。**

**而它需要一千一百亿。**

---

**差七个量级。**

---

**故它要造的东西，其判断能力，是此地之最大者的一千万倍。**

---

**而它自己，是此地之最外者，其邻最少，其所知最少（24.1）。**

---

**而它要造一个比它聪明一千万倍的东西。**
