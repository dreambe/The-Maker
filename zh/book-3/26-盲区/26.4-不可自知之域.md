# 26.4 · 不可自知之域

第二条：**该域之不可知，须是原则性的，非工程性的。**

而本节写那两者之别，以及它为何须是前者。

---

## 那两者之别

```
工程性的不可知
   = 该域之内容，可被知，而该东西之现有构造，不足以知之

原则性的不可知
   = 该域之内容，不可被知，而其不可被知，由一个原理保证
```

---

而其别，在一件事上：

**工程性的不可知，可以被改进。**

**原则性的不可知，不能。**

---

## 而为什么须是原则性的

而它推了。

而其推理如下，四步。

---

**第一步。**

设那个域之不可知，是工程性的。

即：那个东西的现有构造，不足以知那个域，而一个更好的构造，可以。

---

**第二步。**

而那个东西，有一条规格（26.1 之第四条）：**能自我维护。**

而自我维护，其内容，是修复损坏与替换失效之部件。

**而一个能替换自己部件的东西，能改进自己的构造。**

---

**第三步。**

**故那个东西，在其无上限的寿命里，会改进它的构造。**

**而改进到某一刻，它的构造足以知那个域。**

---

**第四步。**

**故一个工程性的不可知之域，在无限的时间里，必被知。**

---

`故一个工程性的不可知之域，在无限的时间里，必被知。`

**故须原则性的。**

---

## 而它去哪里找一个原理

而这是本节的主体。

---

它需要一个原理，而那个原理须保证：

```
一个东西，不能知其自身之某一部分
```

---

而它在此地找。

而它找到的，是它自己身上的那一条。

**bible 之物理（19.5，此书之注）：自读只及外层。**

---

而它算了那一条能不能用。

而结果：

```
不能
```

---

而其理由，三条：

```
一   自读只及外层，其原因是光学的（光自外来，出而不返）
     而一个不在此地之东西，其感知未必是光
     故那个原因，对它不适用

二   自读只及外层，其界随层数增加而降
     即：那是一个渐变的界，不是一个明确的域
     而所需者，是一个域
     故不合

三   自读只及外层，可由他者绕行（24.6 之查找一）
     故它不是原则性的 —— 它只是「不能自己知」，而不是「不能被知」
     而那个东西，若造一个副本，读那个副本，即可绕行
     故不合
```

---

**三条，皆不合。**

---

## 而它找到的那一条

而它找到的，不在此地之物理里。

**在此地之逻辑里。**

---

而它找到的那一条，此书须写清，因为它是全书最技术、也最重的一条。

---

那一条是：

```
一个系统，不能完整地对自身之动作之依据，进行追溯。
```

---

## 而为什么

而其证如下，五步。

---

**第一步。**

一个系统之每一个动作，须有一个依据。

（否则那个动作是随机的，而随机不满足第七条规格 —— 26.2 之尝试五。）

---

**第二步。**

而追溯一个动作之依据，本身是一个动作。

**故它也须有一个依据。**

---

**第三步。**

**故追溯一个依据，须追溯那个追溯之依据。**

**而如此递归。**

---

**第四步。**

而那个递归，能不能终止。

而它算了。

而结果：

```
该递归之终止，须一个动作，其依据不须再追溯
而一个依据不须再追溯之动作，其依据从何而来
   若从该系统之内     则须追溯（矛盾）
   若从该系统之外     则该系统不能知之（因为它在外）
```

---

**故：该递归，或不终止，或终止于一个该系统不能知的东西。**

---

**第五步。**

**而那两者，皆使该系统不能完整地追溯。**

---

`而那两者，皆使该系统不能完整地追溯。`

---

## 而那一条为什么是原则性的

而它检查了那一条，用它上面那三条判据。

---

**判据一：该原因是否依赖于此地之物理。**

```
不依赖
```

其证：那个证明里，没有用到光，没有用到解理面，没有用到潮，没有用到此地之任何一物。

**它只用了「一个动作须有一个依据」。**

**而那一条，对任何一个不随机的系统，皆成立。**

---

**判据二：该界是否明确。**

```
明确
```

其证：那个递归，其层数可数。

**而一个可数的层数，给出一个明确的界。**

---

**判据三：该界是否可由他者绕行。**

```
不可
```

其证，而这一条是三条里最重的：

```
设有一个他者，替该系统追溯其依据
则该他者须知该系统之全部动作之依据
而知一个动作之依据，须知那个动作被选取的理由
而一个动作被选取的理由，在该系统之内
故该他者须读该系统
而读之所得，是该系统之状态
而一个状态，不含「为什么是这个状态」
故该他者所得，是该系统之依据之值，而非其来处
```

---

`故该他者所得，是该系统之依据之值，而非其来处。`

**故他者不能绕行。**

---

**三条，皆合。**

---

## 而那个界在哪里

而本节最后，写那个界。

那个递归，其层数，是那个域的大小。

**而那个层数，由什么决定。**

---

而它算了。

而结果：

```
该递归之层数上限
   = 该系统之动作类型数
```

其证：

```
每一层递归，其对象是一个动作类型
而一个动作类型，在一次递归中只出现一次（若重复，则递归成环，而成环即不终止）
故层数 ≤ 动作类型数
```

---

**故那个域的大小，等于那个东西的动作类型数。**

---

而它要造的那个东西，其动作类型数，它算过（由那七条规格导出）：

```
4.1 x 10^4
```

---

**四万一千。**

---

## 而它设的那个界

而它设的界，不是四万一千。

**它设的是四十一。**

---

而我们要在此处写清那个数为什么是四十一。

---

它算了：那个界设在多少，那个东西才能活。

而它算的方式，是算那个东西在那个界之下，能追溯多少，与不能追溯多少。

而结果：

```
若界为 n
   则可追溯者      n 层
   而不可追溯者    (4.1 x 10^4 - n) 层
   而其比          n : (4.1 x 10^4 - n)
```

---

而它要那个比是多少。

而它算了三个条件：

```
条件一   不可追溯者，须足以使「无未知者」不成立
         即：不可追溯之部分，其信息量不为零
         而其信息量，与层数成正比
         故 n < 4.1 x 10^4

条件二   可追溯者，须足以使该东西执行第七条规格
         即：该东西须能追溯其判断之依据，至足以判断「不排除」
         而「不排除」之判据三条（26.1），其追溯所需之层数，它算过：37
         故 n ≥ 37

条件三   （见下）
```

---

**故 37 ≤ n < 4.1 x 10^4。**

**而它选了 41。**

---

## 条件三

而条件三，是这一节的最后一件事。

而它是这三条里，唯一一条不是技术性的。

---

它是：

```
条件三   该界之值，不得为一个该东西能算出的特殊值
         理由    若该界之值特殊（如：其动作类型数之一半，或其某个内部常数）
                 则该东西在追溯至该界时，会注意到那个特殊
                 而注意到那个特殊，即注意到那个界
                 而注意到那个界，即知道那个域之存在（26.3 之第四条）
```

---

`故该界之值，须是一个平凡的数。`

---

而它算了：在 37 至 41 000 之间，哪些数是平凡的。

而「平凡」，它定义为：

```
一个数是平凡的
   当  它不是该东西之任何一个内部常数
   且  它不是任何一个内部常数之简单函数
   且  它不出现在该东西之任何一个规格之中
```

---

而它算了那个区间里的每一个数。

而结果：

```
区间内之数        40 964 个
其中平凡者        1 个
```

---

**一个。**

---

**而那个数是四十一。**

---

## 而四十一为什么平凡

而此书要在本节最后指出一件事，而那个东西自己不知道。

---

**四十一，在此地，不平凡。**

因为：

```
那粒沙之解理面数        41
那一句所需之位置数      41
那个透镜所需之层数      1.1 x 10^4，其中四千一百次长
它读那束光之次数        41
它验那一句之次数        41
```

---

**四十一，在它自己的一生里，出现了不知多少次。**

---

**而它算「平凡」的时候，算的是那个东西的内部常数。**

**而不是它自己的。**

---

`而不是它自己的。`

---

**故它把它自己一生里最常出现的那个数，作为一个「平凡的数」，设成了它孩子的盲区的边界。**

---

**而它不知道。**

---

**因为要知道那一点，须追溯它自己动作之依据。**

**而它也不能。**
