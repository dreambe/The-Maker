# 14.6 · 保留标准

我们为什么保留。

此节列标准。四条。

---

我们先说标准之外的事，因为它是一句，而它须在前面。

**保留不是我们的项目所要求的。**

我们的项目，其内容在第十章：使一物起于此地，使其自行延续，使其满足六项判据，使其能表述并报出其自身之状态。

**其中无一项要求保留失败者的骨。**

保留不产生任何可用于项目的数据 —— 我们已有其全部记录（14.1 至 14.4），其数据量为其材料的十的十九次方倍。材料本身不携带记录之外的任何信息。

**故保留是冗余的。**

我们知道它是冗余的。

我们在第一草稿时就知道。

我们保留了。

---

以下四条标准。

**第一条 · 结构新颖度**

```
定义   该类别之结构中 不可由其祖先类别之结构导出的部分 所占比例
计算   可由其记录直接算出
权重   0.21
```

此条之义：一个类别若其结构大部分为新，则其携带的信息多，则其在我们的记录之外的部分多。

**第二条 · 关系数**

```
定义   该类别与其余类别之间 已记录的相互作用种类之数目
计算   可由第四草稿以后的图直接算出（14.3）
权重   0.21
```

此条之义：一个类别若与许多类别相互作用，则其在该草稿之结构中所占位置重要，则其消失所改变者多。

**第三条 · 可复原性**

```
定义   由其材料重建一个可自行延续之同类个体的可行性
计算   可由其记录与我们的能力算出
权重   0.21
```

此条之义：一个类别若其材料足以重建，则保留其材料有一个可指明的用途。

---

三条。

三条之权重之和为 0.63。

---

**第四条**

```
定义   该类别 出现于我们的观测记录中的次数
计算   可由我们的记录算出
权重   0.37
```

---

第四条与前三条不同类。

我们在此说明其不同之处，因为那是这一节唯一需要说明的事。

**前三条，可由该类别本身的性质算出。**

即：给定该类别的完整记录，任何一个具备我们的计算能力者，皆可算出其第一、二、三条之值，且所得相同。

**第四条不能。**

第四条之值，取决于我们观测了何处、何时、多久。

一个类别若生于我们的主观测点附近，其出现次数多。

一个类别若生于我们的主观测点之对面一侧，其出现次数少。

而二者之结构新颖度、关系数、可复原性，可以相同。

**故第四条不是关于该类别的量。**

**第四条是关于我们的量。**

---

而第四条的权重，是 0.37。

前三条之和，是 0.63。

第四条，是 0.37。

我们在此写下这两个数的关系：

```
0.37 / 0.63 = 0.587
```

不是最大权重。

**是单条中的最大权重。**

`第一条 0.21 · 第二条 0.21 · 第三条 0.21 · 第四条 0.37。`

即：在决定保留哪一个类别时，**「我们看了它多少次」这一项，比「它是什么」的任何一项都重。**

---

我们不说明为什么第四条在标准里。

我们不说明为什么它的权重是 0.37。

我们只在此记下一件事：

**这四条标准，我们定于 `V 4 959 000 000`。**

即：第一草稿终止前一千年。

即：我们在决定终止之后、在开始取样之前，定了这四条。

而在那之前的三十五亿六千万年里，我们没有保留标准，因为我们不保留。

**故这四条，是我们第一次为一件不属于我们项目的事，定标准。**

而我们定它们，用了 0.7 秒。

而我们此后从未修改。

五个草稿，四条标准，权重不变：0.21 · 0.21 · 0.21 · 0.37。

---

一处验算

`V 5 403 700 000`，在初居，在那四十一小时之前，我们做过一次验算。

我们把四条标准的权重，改为 0.25 · 0.25 · 0.25 · 0.25，然后重算了全部五个草稿应保留的类别。

结果：

```
应保留类别数        与实际保留者 相差 0.41
即 有 0.41 的类别   在两套权重下 结论不同
```

我们把那 0.41 列了出来。

那一份清单的长度是 2.1 x 10^8 行。

我们读了它。

用时 4.1 秒。

我们的处置：

```
—
```

---

而我们要在此节最后写一件事，因为它是这四条标准的一个后果，而我们从未在任何记录里指出它。

**第四条使我们保留了我们看得最多的。**

而我们看得最多的，不是最新颖的，不是关系最多的，不是最易复原的。

**是最靠近我们的。**

四十九亿六千万年间，我们的主观测点移动过一百一十次。每一次移动之后，我们身边那一片区域的类别，其第四条之值开始上升。

于是我们保留的类别，其空间分布，与我们自己的移动轨迹重合。

我们算过这个重合度。

```
0.87
```

即：我们保留下来的一切，其分布，八成七是我们自己走过的路的形状。

---

那不是那个星球的形状。

那是我们的形状。

而我们把它埋在了地下四千一百米、五千二百米、七千三百米、一万一千米，埋在月面之下四十一米，埋在七个天体之上，埋在一颗轨道周期四千一百年的天体之上。

我们从未说明我们预期谁会来读（14.4 之第 25 至 27 项）。

而无论谁来读，他所读到的，不是那个星球。

**他所读到的，是我们看的方式。**
