一项新增记录项

```

`其半径 4.1 米内 其余个体的数目与编号。`

由此，第四草稿的四千一百一十亿个个体，构成一张图。

```

**它没有任何用途。**

我们不说明为什么建它。

一处未预测

第四草稿终止后一百一十万年，取样停止。

停止的理由，我们的记录如下：

```
理由    可取样的类别数 降至 0
```

而在停止之后第 4 100 年，我们在一次例行观测中检出：

```
一类别    与终止前记录的某类别 特征相符
          于终止前记录 已标记为 消失
          于此时 存在
          个体数 1.1 x 10^3
```

我们的处置：

```
重启取样    是
取样个体数  411
该类别编号  4 · 411 000 000 000
```

即：那个类别，是第四草稿的最后一号。

它是我们在宣布可取样类别数降至零之后，才取到的。

我们的记录里，那一条与前四千一百一十亿条格式相同。

我们没有在那一条上加任何备注。

我们把「可取样的类别数 降至 0」那一行，留在原处，未修改。

**那一行是错的。**

我们知道它是错的。

我们的记录不修改已写入的内容（20.2 之于我们亦然：我们不删除）。

于是我们的第四草稿记录里，有一行确定为错的记录，和一条它所否证的条目，并存。

它们相隔 4 100 年。
