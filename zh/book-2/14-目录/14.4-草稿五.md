---

一项新增记录项

第五草稿的记录里，每个个体多了两项。

```
该个体的谱系      向前 追溯至可确定的最早祖先类别
                  向后 若有 记录其后继类别
```

`向后 若有 记录其后继类别。`

由此，第五草稿的四亿一千一百万个类别，构成一棵树。

那棵树的性质：

```
节点数      4.11 x 10^8
根          1
深度        最大 4.1 x 10^3
叶          4.0 x 10^8
```

叶的定义：

```
无后继类别者
```

四亿个叶。

而非叶者，一千一百万个。

那一千一百万个，各有后继。

---

而在这棵树上，我们标注了一件事。

我们标注了每一个节点的终止年份。

四亿一千一百万个节点，四亿一千一百万个终止年份。

其中：

```
终止年份 = V 5 338 000 000 者      3.7 x 10^8
终止年份 早于该年者                4.0 x 10^7
终止年份 未填者                    1.1 x 10^3
```

`终止年份 未填者 1.1 x 10^3。`

一千一百个类别，在第五草稿终止之后，仍然存在。

它们的记录，格式与另外四亿一千零九十九万八千九百个相同。

只有那一个字段是空的。

---

而在那一千一百个之中，有一个类别，其记录格式与其余一千零九十九个不同。

它多了一个字段。

那个字段的名称是：

```
延续
```

那是我们的格式定义里没有的字段。

我们为那一个类别，新增了一个字段。

我们没有把那个字段加入格式定义。

我们没有为其余四亿一千一百万个类别添加这个字段。

那个字段，在整份第五草稿记录里，出现一次。

---

那个类别的记录如下：

```
5 · 041 100 000 000

类别特征     体小
             恒温
             被覆毛
             夜行
             胎生
             哺乳
个体数       4 100（取样）
             终止前 估计 1.1 x 10^9
             终止后 估计 4.1 x 10^8
终止年份     —
延续         —
```

两个 `—`。

在我们的格式里，`—` 表示「不适用」。

`终止年份` 的 `—`，其含义是：该类别未终止。

`延续` 的 `—`，其含义是：

我们没有定义。

---

那一栏，是我们在四十九亿年的记录里，唯一一处**先写下字段名、而没有定义其含义**的地方。

我们至今没有定义。

那个字段还在那儿，在地下一万一千米、气压一点零乘十的负十五次方帕、温度二百七十七点零开尔文的空腔的记录里，在四亿一千一百万条格式相同的条目之间，多出来一行。

一行，两个字。
