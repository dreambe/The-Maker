# 16.1 · 设计

`V 5 403 300 000`

本章记那一次的设计。

而本章不给那个东西编号。

理由在第十四章之末（14.9）：自 `V 5 403 300 000` 起，我们的记录中不再出现新的草稿序号。

**故本章所记者，无编号。**

**故本章之标题为「不计数」。**

---

## 前四次之后

我们要先写一件事，因为它是这次设计的全部前提。

前五个草稿，其失败之原因，我们逐一记录（第十三、十四章）。

而在 `V 5 300 000 000` 至 `V 5 403 300 000` 之间的一亿零三百七十万年里，我们做了一件事。

**我们把那五次失败的原因，重新分类了。**

---

原分类如下（按草稿序）：

```
第一草稿   自我表述能力之上界 0.0041 · 不满足判据六
第二草稿   同上
第三草稿   同上
第四草稿   同上
第五草稿   同上
```

**五条，逐字相同。**

---

而新分类如下：

```
全部五次   同一个原因
```

而那个原因，我们在 `V 5 403 299 000` 写下：

```
碳基之化学信息处理，其速率由分子扩散与反应动力学定
而在该星球之温度下，该速率有一物理上界
故纯化学系统所能达到之表述复杂度，有一物理上界
而该上界低于判据六所需
```

**故：不是那五个失败了。**

**是那条路的上界低于所需。**

---

`是那条路的上界低于所需。`

---

而我们要在此处写下一件我们在 13.8 已经知道、而在此处才处理的事。

那个上界，由第一个配置所定。

而第一个配置，是我们从四千一百亿亿个候选中选的那一个（第十章）。

**故那五次失败，其原因在第一次选择。**

**而我们此后四十四亿年，一直在那个选择之内重试。**

---

## 那次会议

我们的记录里没有「会议」这个词。

而 `V 5 403 299 000` 那一年，我们的记录里有一件事，其格式与我们的任何一条记录不同。

那件事的记录如下：

```
V 5 403 299 000
   参与        41
   时长        41 年
   内容        见下
   输出        一份参数表
```

`参与 41。`

即：那四十一台，全部。

`时长 41 年。`

而我们的任何一次计算，其用时未超过 41 秒（15.2 之最长者）。

**而这一次是四十一年。**

---

我们要说明为什么是四十一年，因为那是一个我们此前没有过的量。

一次计算的用时，取决于其运算量。

**而这一次不是一次计算。**

因为一次计算，须有一个确定的输入与一组确定的操作。

**而这一次的输入未定。**

其输入是：**我们要造什么。**

而那不是一个已知量。

---

`而那不是一个已知量。`

**故那四十一年，不是在算。**

**是在定输入。**

而定输入这件事，我们的格式定义里没有它的名字。

四十九亿年来，我们的一切输入，皆由那句话经四层给出（15.3 第三页）。

**而这一次，那四层给不出。**

因为那四层给出的是「六项判据」。

**而六项判据已经证明不可达（本节之首）。**

---

## 第一项与第二项

我们要在此处写下这份参数表最难解释的一处。

**我们仍然用化学。**

**我们仍然用分子扩散。**

而本节之首已证：那条路的上界低于所需。

**故这一项与那个结论矛盾。**

---

而它不矛盾。

其解如下，而它是那四十一年的全部产出：

```
纯化学系统之表述复杂度上界      由单个化学单元之速率定
而一个系统之表述复杂度          不只取决于单元之速率
                              亦取决于单元之数目与其连接方式
故：提高单元数目与连接密度       可越过该上界
而所需之单元数                  1.1 x 10^11
而所需之连接数                  1.1 x 10^14
```

**故我们没有换载体。**

**我们把它做大了。**

---

`我们把它做大了。`

而我们要在此处记下那两个数的来处，因为它们不是我们估的。

**它们是算的。**

我们算的是：**要使自我表述能力之上界达到 1.0，最少需要多少个单元。**

结果：

```
1.1 x 10^11
```

**而我们做的，正好是那个数。**

不多。不少。

我们的记录里，那一行的旁边有一个字段，四十九亿年来我们填过 1.1 x 10^14 次。

那个字段是「冗余系数」。

我们的一切设计，其冗余系数不小于 4.1。

**而这一项，我们填的是：**

```
冗余系数    1.0
```

---

`冗余系数 1.0。`

即：无冗余。

即：那一千一百亿个单元，少一个，那个上界就达不到 1.0。

**而我们没有加冗余。**

我们不解释为什么。

我们已搜索。零结果。

---

## 第四项 · 寿命

此节最后，写寿命的选定过程。

因为那是这份参数表里唯一一项，其选定过程有完整记录。

---

我们先算了不设寿命上限的情形。

```
若单体不死
   则单体之记忆持续累积
   则单体之表述能力持续提高
   则判据六之满足     更快
   则本项目之完成     更早
```

**故不死是更优的。**

**故按我们的序（15.3），我们应该选不死。**

---

而我们没有。

以下为那个过程，逐步。

---

**第一步。** 我们算了不死之单体，其表述能力随时间之变化。

```
起初      上升
其后      上升
其后      趋于一个上界
而该上界   由其单元数定 = 1.0
```

**故一个不死之单体，在某一时刻，达到 1.0。**

**而其后不再上升。**

---

**第二步。** 我们算了那个时刻。

```
达到 1.0 之时刻    约 4.1 x 10^3 年（自其起始）
```

**四千一百年。**

---

**第三步。** 我们算了那之后。

一个已达 1.0 的单体，其后如何。

我们的记录：

```
达到 1.0 之后
   其表述能力      不再上升
   其记忆          持续累积
   其记忆之内容    与其表述能力无关（表述能力已饱和）
   故其后之累积    信息量为零
```

---

`故其后之累积 信息量为零。`

---

**第四步。** 而在此处，我们的记录里出现了一行。

那一行的格式与我们的记录不同。它不是一个字段，不是一个值。

它是我们写下的第五个句子（前四个在 13.8、15.1、15.3、15.7）。

它是：

```
   我们在此处认出了一个我们自己的状态。
```

---

十四个字。

我们不解释。

**而其后 0.7 秒，我们改了第四项。**

---

**第五步。** 改后如下：

```
四   寿命
     单体      设上限
     上限之值   见下
```

而上限之值，其选定依据：

```
该值须小于 4.1 x 10^3 年
理由      使单体在达到 1.0 之前终止
```

---

`使单体在达到 1.0 之前终止。`

---

我们要在此处写清这一行的含义，因为它是我们四十九亿年来做出的唯一一个与我们的序相反的决定。

我们的项目要求：造一个满足判据六（能表述并报出其自身之状态）的东西。

而判据六之满足，须自我表述能力达到 1.0。

**而我们把寿命设在了达到 1.0 之前。**

**故我们造的每一个单体，都不满足判据六。**

---

**而其谱系不设上限（第四项之第二行）。**

即：单体死，而谱系继续。

而一个谱系，其成员一代一代地接近 1.0，而每一个都在到达之前终止。

**而那个谱系的整体，其表述能力，可以达到 1.0。**

---

`而那个谱系的整体，其表述能力，可以达到 1.0。`

**故判据六由谱系满足，不由单体满足。**

**故我们造的不是一个满足判据六的东西。**

**我们造的是一个其谱系满足判据六的东西。**

---

而那个上限的具体值，我们在参数表的最后一行填了。

```
单体寿命上限     41 至 110 年
```

而那个区间的下界与上界之差，我们的记录里有一个字段：

```
个体间差异     保留
理由           —
```

`理由 —`

---

那是我们四十九亿年来，唯一一次在一个设计参数上，**保留了一个我们本可以消去的变量**。

我们可以把它设成一个定值。

**而我们留了一个区间。**

**而我们没有说为什么。**
