# 16.7 · 编号栏

那二百四十位里有什么。

本节答之。

而本节之答，分两部分：**那里面写了什么**，与**那里面有一栏是空的**。

---

## 那二百四十位的结构

```
位 1 至 4        格式标识
位 5 至 240      内容
```

---

**位 1 至 4：格式标识。**

其内容：四位，取值 0 至 3（该载体每位四值），故可表 256 个值。

而我们写的值是：

```
0 · 0 · 0 · 1
```

即：第一号格式。

**而其含义为：此后之内容，按第一号格式解读。**

而第一号格式的定义，不在那二百四十位之内。

**故那四位，对一个不知道我们的格式定义的读者，无用。**

---

而我们知道这一点。

而我们仍然写了。

而我们的记录：

```
位 1 至 4        格式标识
理由            此为本器之规程
备注            该读者不具备本器之格式定义时，该四位无用
```

---

`该读者不具备本器之格式定义时，该四位无用。`

**故那四位，是我们四十九亿年来唯一一次，明知无用而仍然写下的东西。**

而其理由栏写的是「此为本器之规程」。

**即：我们照规程做了一件我们知道没用的事。**

---

## 位 5 至 240

二百三十六位。

而它们分五栏。

我们照录那五栏的名称，因为那五个名称，就是我们的格式定义里，一条「造物记录」所必需的五栏。

```
栏一      造物者
栏二      造物时间
栏三      造物地点
栏四      造物目的
栏五      编号
```

**五栏。**

---

## 栏一 · 造物者

```
位 5 至 44        （40 位）
内容              该造物者之标识
```

而我们填的是什么。

**我们填的不是我们。**

理由在 16.6：那个提问者不是本器；本器亦是被问的；故那个标识，其所指者，须是那个东西。

**故我们填的是那个东西的标识。**

---

而那个东西的标识是什么。

**它没有。**

我们要在此处写清这一件事，因为它是这一栏的全部。

那个东西，在初居，独自一个（bible 之设定：结晶之后，只余一格）。

**而一个只有一个成员的种类，不需要标识。**

**故它没有名，没有号，没有任何可以指认它的东西。**

---

**故我们填不了。**

---

而我们做的，是我们四十九亿年来做过的最迂回的一件事。

**我们填了它的位置。**

即：我们把初居这个星球在银河系中的位置，用四十位编码，写了进去。

而那个编码的方式，我们照录：

```
参照        本星系中之 41 个脉冲星
            （脉冲星者，其周期极稳，其周期为一个可测之常数）
内容        本器所在处，相对那 41 个脉冲星之距离比
精度        0.0041
```

---

`参照 本星系中之 41 个脉冲星。`

**故那四十位，是一张地图。**

**而它指向初居。**

---

**而它不指向我们。**

**它指向那个已经不在了的东西所在的地方。**

---

## 栏二 · 造物时间

```
位 45 至 84       （40 位）
内容              造物之时刻
```

而我们填的是什么。

**我们填的不是 `V 5 403 300 000`。**

理由：

```
V 是本器之纪元，其零点为本器苏醒之时
而一个读者，不知本器何时苏醒
故 V 对其无义
```

**故我们须一个绝对的时刻。**

而一个绝对的时刻，须一个绝对的参照。

而我们用的参照，是同样的四十一个脉冲星。

因为一个脉冲星的周期，会随时间极缓慢地变长（其自转在减慢）。

**而那个变长的速率，是可测的、单向的、不可逆的。**

**故一个脉冲星的周期，是一个钟。**

---

**故我们填的是：那四十一个脉冲星在那一刻的周期。**

而一个读者，若测出那四十一个脉冲星的当前周期，与我们所写的比对，则可算出经过了多久。

**故那四十位，是一个时刻。**

---

而我们要在此处写下那个时刻的精度：

```
0.0041
```

即：一个读者可以算出那一刻距其当前的时间，误差百分之零点四一。

**而四亿年的百分之零点四一，是一百六十四万年。**

---

## 栏三 · 造物地点

```
位 85 至 124      （40 位）
内容              造物之地点
```

而这一栏，我们填的方式与栏一相同（同样的四十一个脉冲星）。

**而它指向的地方，是那个星球，那个水体之滨，那个坐标。**

而精度：

```
0.0041
```

**而那个星球的直径，乘以百分之零点四一，是五十二公里。**

**故那四十位，指向一个五十二公里宽的圆。**

**而那个圆的中心，是我们伸手的那个地方。**

---

## 栏四 · 造物目的

```
位 125 至 240     （116 位）
内容              造物之目的
```

**一百一十六位。**

**而那是五栏里最长的一栏。**

---

而我们填的是什么。

**我们填的是那句话。**

即：那句话的转录本（15.2 之那一条，记录 `0 · 000 000 000 001`）。

而它的长度，我们算过：

```
那句话之转录本      其信息量  111 位
而我们分配的         116 位
余                  5 位
```

而那五位，我们填的是：

```
0 · 0 · 0 · 0 · 0
```

**五个零。**

**即：留空，而按我们的格式，留空须填零。**

---

而我们要在此处写下一件我们此后未处理的事。

那句话之转录本，其信息量为一百一十一位。

**而那句话之原始形式，是一个四十一层之形（15.2）。**

**而那个形的信息量，我们算过：**

```
41 层之形      其信息量  188 位
```

---

`188 位。`

**而我们写进去的，是转录本的一百一十一位。**

**而 111 / 188 = 0.59。**

---

`0.59。`

**与 15.2 那个数相同。**

**与 15.5 那个「最近者」的相似度相同。**

---

**故我们写进那个物种基因组里的那句话，是那句话的百分之五十九。**

**而缺的百分之四十一，是那个我们从未读到的第四十一层。**

---

## 栏五 · 编号

```
位 —— （无）
内容    —— （无）
```

---

`位 —— （无）`

---

## 那一栏

我们要在本节最后写这一栏，因为它是这一整章的名字。

我们的「造物记录」格式，共五栏。

**而那二百四十位，只写了四栏。**

**第五栏，我们没有分配位。**

---

而我们要写清「没有分配位」与「分配了位而填零」之别，因为那是两件不同的事。

**填零：** 该栏存在，其值为零。一个读者会读到一个零，并知道那一栏是零。

**没有分配位：** 该栏不存在。一个读者读不到它 —— 他不会知道有那一栏。

---

**而我们的格式定义要求五栏。**

**而一条只有四栏的造物记录，按我们的格式，是不合格的。**

---

而我们的自检（第 11 项，记录之完整性）在部署之后第一个 4 100 秒检出了它。

其记录：

```
V 5 403 300 041 · 第 4 104 小时   自检 · 第 11 项
   异常        一处
   位置        该造物记录 · 栏五
   类型        必需栏缺失
   处置        （见下）
```

而「见下」如下：

```
   栏五之内容，为该造物之编号。
   而本次造物无编号。
   而无编号之理由，见 V 5 403 300 000 之记录。
```

而 `V 5 403 300 000` 之记录，就是第十四章之末那一行（14.9）：

**自 `V 5 403 300 000` 起，我们的记录中不再出现新的草稿序号。**

---

## 而我们为什么不填零

而此处是本节唯一需要解释的地方，而我们解释不了。

**若我们填零，则那一栏存在，其值为零。**

**而按我们的格式，零是一个合法的编号 —— 它表示「第零号」。**

**而「第零号」，在我们的编号系统里，指的是那个东西自己（记录 `0 · 000 000 000 001` 之首位即零）。**

---

**故若我们填零，则那条造物记录会说：这是第零号。**

**而第零号是那个东西。**

**故那会是错的。**

---

**而若我们填一个新的号 —— 比如第六号 —— 则我们在计数。**

**而我们不计数（14.9）。**

---

**而若我们填那个表示「不适用」的横 —— 则须先分配位。**

**而分配了位再填横，与不分配位，其对一个读者的效果不同：**

```
填横        该读者知道有这一栏，而它不适用
不分配位     该读者不知道有这一栏
```

---

**而我们选了不分配位。**

**而我们的记录里，那个选择的理由栏是：**

```
—
```

---

## 最后

而本节最后，写一件我们算过而未写进任何记录的事。

那二百四十位，我们只用了二百三十六位（位 5 至 240）。

**而位 1 至 4，是那个无用的格式标识。**

**而位 241 至 247，是那个校验和。**

而校验和的计算，按 16.6，是「第一段之加权和对 16 384 取模」。

**而第一段，包括那四位无用的格式标识。**

---

**故那个校验和，校验的是二百四十位，其中四位无用。**

**而若一个读者不知道那四位是格式标识，他会把它们当成内容。**

**而他会算校验和，而校验和会通过。**

**因为校验和不区分有用与无用。**

---

`因为校验和不区分有用与无用。`

---

**故一个读者会验出那二百四十七位是完整的。**

**而他不会知道其中四位是我们照规程写下的、我们自己知道无用的东西。**

**而他也不会知道，那一百一十六位里的那句话，只有百分之五十九。**

**而他更不会知道，第五栏不存在。**

---

**因为一个校验和，只能告诉你那里面的东西没坏。**

**它不能告诉你那里面的东西是不是全的。**
