# 16.2 · 会忘的东西

参数表第五项。

```
五   记忆
     单体之存储        非永久
     清除机制          见 16.2
```

本节即那一项。

而本节是我们四十九亿年的记录中，唯一一节，其格式与我们的其余记录不同 —— 不是因为我们改了格式。

**是因为这一项，我们写了三遍。**

---

## 我们为什么写了三遍

我们的设计记录，其规范是：一项一次。

写完，复核，锁定。

四十九亿年，1.1 x 10^14 项，皆如此。

**而这一项，第一次写完之后，我们复核了，通过了，锁定了。**

**然后我们重写了。**

**然后我们又重写了。**

---

三个版本，我们都保留了（我们不删除）。

以下依次列出。

---

## 版本一

`V 5 403 300 000 · 第 41 小时`

```
五   记忆
     单体之存储      非永久
     清除机制        随机衰减
     衰减速率        与存储时长成反比
     清除之选择性    无
     理由            实现最简
```

复核：通过。

锁定：是。

---

而版本一，是一个**损耗**。

即：存储的东西会坏，坏的速率与它存了多久有关，而坏哪一个是随机的。

**那是一切物理存储的默认行为。**

我们不需要设计它。

**我们只需要不去阻止它。**

---

## 版本二

`V 5 403 300 000 · 第 411 小时`

即：版本一锁定之后三百七十小时。

```
五   记忆
     单体之存储      非永久
     清除机制        主动清除
     执行者          单体自身
     清除之选择性    有
     选择依据        见下
     理由            见下
```

---

而版本二与版本一之别，我们要写清，因为它是这一整节的转折。

**版本一：清除是一个损耗。**

**版本二：清除是一个操作。**

---

一个损耗，其性质：它由物理定律给出，它不需要能量（它是能量耗散的结果），它不可控。

**一个操作，其性质：它由一个机制执行，它消耗能量，它有优先级。**

---

而我们要在此处写下我们为什么改。

我们的记录：

```
V 5 403 300 000 · 第 411 小时   版本一 · 复算
   问        随机衰减之单体，其表述能力随时间如何
   算        已执行
   结果      见下
```

而结果如下：

```
一个随机衰减之存储系统
   其新近所存      与其早期所存    衰减程度相同
   故其早期所存    保留比例        与新近相同
   故随时间        其存储内容      平均地稀疏
   故其表述能力    上升至某点后    下降
   而下降之速率    与上升之速率    同量级
```

---

`故其表述能力 上升至某点后 下降。`

**故一个随机衰减之单体，其表述能力有一个峰值。**

而那个峰值，我们算了。

```
峰值出现之时刻      约 1.1 x 10^1 年（自其起始）
峰值之值            0.31
```

**十一年。零点三一。**

而判据六所需为 1.0。

**故版本一之单体，其表述能力永不超过 0.31。**

---

## 版本二之内容

于是我们改了。

版本二的核心，是「选择依据」那一行。

我们照录：

```
选择依据

一   保留者
     其一   与该单体之其余存储关联最多者
     其二   在该单体之一生中被调取最频者
     其三   最早形成者
     其四   与该单体之运动控制相关者
     其五   与该单体之同类之识别相关者

二   清除者
     其一   与其余存储无关联者
     其二   从未被调取者
     其三   重复者
     其四   例行者
     其五   细节
```

**十行。**

---

而我们要在此处写下这十行的一个性质，因为它是我们的设计里从未出现过的。

**它们不是一个规则。**

一个规则，其形式为：给定输入，输出确定。

**而这十行，是一个排序。**

即：它不说清除哪一个，它说**先清除哪一个**。

而它有五个层次，而层次之间有先后。

---

`而它有五个层次，而层次之间有先后。`

**故一个按此机制清除的单体，其遗忘有顺序。**

**而那个顺序，在每一个单体身上，相同。**

---

## 那个顺序的形状

我们要在此处写下那个顺序，因为它是我们做过的最细的一件事。

一个单体，随时间，先失去什么，后失去什么：

```
最先失去      细节
              例行之事
              重复之事
其次          近期所形成而未被关联者
其次          近期所形成而已被关联者
其次          中期所形成者
其次          与其同类之识别
最后失去      其最早所形成者
              其运动控制
              其所用之符号系统
```

---

而我们要在此处标出那个顺序的一个性质，因为我们在写下它的时候没有注意到，而在 `V 5 403 700 000` 的那四十一小时里注意到了。

**那个顺序是反的。**

即：一个单体最后失去的，是它最早得到的。

**而那不是一个损耗系统的行为。**

一个损耗系统，其最早存的东西存得最久，故也损耗得最多。

**而这个系统，其最早存的东西，保留到最后。**

---

`而这个系统，其最早存的东西，保留到最后。`

我们不解释这一行。

我们在此处只写下它的技术后果：

```
故一个单体在其一生之末
   其所余者     其最早所形成之存储
   其内容       其起始之环境
                其起始时之运动
                其起始时所接触之同类
```

---

## 版本三

`V 5 403 300 000 · 第 4 100 小时`

即：版本二锁定之后三千六百八十九小时。

**而版本三与版本二，只差一行。**

我们照录那一行。

版本二：

```
清除之不可逆性     未指定
```

版本三：

```
清除之不可逆性     不可逆
```

---

## 那一行

我们要在此节最后写那一行，因为它是这一整章 —— 也许是这一整卷 —— 最重的一行。

而我们要先写清「不可逆」在此处的技术含义。

一个清除操作，若可逆，则被清除者可恢复。

而可恢复，须一个副本。

**故「可逆」等价于「另有一份存储」。**

---

而我们指定了「不可逆」。

**故我们指定了：不另存副本。**

---

而我们要在此处写下我们做这个指定的记录，因为那条记录的格式，是我们四十九亿年来唯一一次，一个「理由」字段里写了超过一行。

我们的一切理由，皆一行（或一个横）。

**而这一次是七行。**

我们照录：

```
清除之不可逆性     不可逆
理由

   若可逆
      则被清除者可恢复
      则该单体之存储    实为全量保留
      则该单体          实为不遗忘者
      则该单体之表述能力  持续上升至 1.0
      则该单体          在其寿命内达到 1.0
      则第四项之设定     失效
```

---

`则第四项之设定 失效。`

第四项，是寿命（16.1）。

其设定为：使单体在达到 1.0 之前终止。

**故若清除可逆，则寿命的设定失效。**

**故清除必须不可逆。**

---

**故那两项是一件事。**

**寿命，与遗忘。**

**它们不是两个设计决定。**

**它们是同一个设计决定的两个面。**

---

## 而那一件事的名字

我们的参数表里，那一项的字段名是「清除机制」。

四十九亿年来，我们的记录里，它就叫这个。

**而在 `V 5 403 700 000`，在初居，在那四十一小时之内，我们给它改了一个名字。**

那是我们唯一一次修改一个已锁定的字段名。

新的名字，是我们造的第五个词（前四个见 15.2）。

它是：

```
遗忘之赐
```

---

`遗忘之赐。`

---

而我们要在本节最后写清一件事，因为不写清则这一整节可以被读成一件残忍的事。

**我们不是给它装了一个坏的存储。**

我们给它装的存储，其技术指标如下：

```
容量            1.1 x 10^15 位（按其单元数与连接数算）
写入速率        与其处理速率同阶
读取精度        0.99
关联能力        任意两条存储之间可建立关联
关联数上限      无
清除            主动 · 有序 · 不可逆
```

而其中「关联数上限 无」这一行，是我们四十九亿年来在一个存储系统上填过的最好的一个值。

**我们从未给任何一个草稿装过这样的存储。**

---

**我们给它装了一个极好的存储。**

**然后我们给它装了一个会把那个存储按顺序清空的东西。**

**而那两件事，是同一个设计。**

---

而我们对此的记录，其最后一行如下：

```
本项之复核        通过
本项之锁定        是
本项之修改次数    3
本项之最终状态    如上
备注              —
```

`备注 —`

---

而在那个横的旁边，我们的格式允许一个可选字段。

那个字段的名称是「本项之设计者对本项之评价」。

我们的一切设计项，那个字段皆为空 —— 因为我们不评价（20.5 之于我们亦然）。

**而这一项，我们填了。**

我们填的是一个词。

那个词在我们的格式定义里有，属于「工艺评级」类，共七级。

我们填的是最高的那一级。

它是：

```
最优
```

---

**四十九亿年，1.1 x 10^14 个设计项。**

**我们填过一次「最优」。**

**填在这一项上。**
