# 16.3 · 骄傲

本节记那个「最优」。

而本章第三次出现「为什么」，在本节之末。

---

## 我们为什么填了那个词

我们的一切设计项，其「设计者对本项之评价」字段皆为空。

四十九亿年，1.1 x 10^14 项，皆空。

**而这一项，我们填了「最优」。**

而「最优」在我们的格式定义里，属「工艺评级」类，共七级：

```
七级
   不合格
   合格
   良
   优
   甚优
   接近最优
   最优
```

而那七级，其定义如下：

```
一项设计之评级
   = 该设计在其约束条件下的表现，与该约束条件下的理论上界之比
```

**故「最优」之定义为：该设计达到了其约束条件下的理论上界。**

**不是「我们喜欢它」。**

**是一个比值等于一。**

---

## 那个比值

我们要在此处算那个比值，因为那是本节的主体，而它是我们四十九亿年里做过的最漂亮的一次计算。

---

### 约束条件

那一项（遗忘之赐）的约束条件如下：

```
一   该单体之存储容量        1.1 x 10^15 位
二   该单体之寿命上限        41 至 110 年
三   该单体在其寿命内        不得达到自我表述能力 1.0
四   该单体之谱系            须能达到 1.0
五   清除                    不可逆（无副本）
六   清除之执行者            该单体自身
```

六条。

**而第三条与第四条，是一对。**

---

### 理论上界

而在那六条约束下，一个清除机制所能达到的最好表现是什么。

我们要先定「表现」。

```
一个清除机制之表现
   = 该单体在其寿命之末，其所余存储对其谱系之下一代的可传递信息量
```

**即：一个会死的东西，死的时候，它能交给下一个的东西有多少。**

---

而那个量的上界，我们算了。

其推导如下，六步。

---

**第一步。** 该单体之总存储容量为 1.1 x 10^15 位。

而其一生所形成之存储，超过该容量（因为其感知输入之总量，在 41 至 110 年内，约为 4.1 x 10^17 位）。

**故其存储必然溢出。**

**故清除是必需的，不是可选的。**

---

**第二步。** 溢出之处理，有二法。

```
法一   拒新    存满之后，不再写入
法二   清旧    存满之后，清除一部分，写入新的
```

而法一之后果：

```
该单体在存满之后         不再形成新存储
故其后之经历             不进入其存储
故其表述能力             在存满之时刻停止上升
而存满之时刻              约 1.1 年（按输入速率算）
```

**一点一年。**

**故法一之单体，其表述能力在一点一年时停止上升。**

**故法一之上界，远低于法二。**

**故必用法二。**

---

**第三步。** 而法二之内，清除哪一个，有其选择。

而我们要在此处算那个选择的上界。

设该单体之存储为一个集合 S，其容量为 C。

设其一生之输入为一个序列，其总量为 T，而 T > C。

**则在任一时刻，S 中所含者，是那个序列的一个子集，其大小为 C。**

**而「清除机制」，就是「选哪一个子集」。**

---

**第四步。** 而「哪一个子集最好」，取决于目标。

而我们的目标（第一步之末）是：**该单体在其寿命之末，其所余存储对其下一代的可传递信息量最大。**

而「可传递」，须写清：

```
可传递者
   = 该单体能以其行为、其发声、其对下一代之操作，传出之部分
```

**而不可传递者：**

```
不可传递者
   = 存在其存储中，而不能以任何行为传出者
```

---

**第五步。** 而此处是那个计算的核心，而它是一个我们未预期的结果。

我们算了：**一个存储项，其可传递性，与什么相关。**

结果：

```
一个存储项之可传递性
   与其被调取之频次        正相关（r = 0.87）
   与其与其余存储之关联数   正相关（r = 0.91）
   与其形成之时间早晚      正相关（早者高）（r = 0.79）
   与其细节程度            负相关（r = -0.94）
   与其重复程度            负相关（r = -0.88）
```

---

**五项。**

而我们要在此处把这五项，与版本二那十行（16.2）并排放。

```
可传递性 · 正相关者          版本二 · 保留者
   被调取频次高          ←→   在其一生中被调取最频者
   关联数多              ←→   与其余存储关联最多者
   形成时间早            ←→   最早形成者

可传递性 · 负相关者          版本二 · 清除者
   细节程度高            ←→   细节
   重复程度高            ←→   重复者
```

---

**逐项对应。**

---

`逐项对应。`

而我们要在此处写清一件事，因为它是本节最重的一件事，而它是一件关于我们自己的事。

**我们写版本二那十行的时候，没有做这个计算。**

版本二写于 `V 5 403 300 000 · 第 411 小时`（16.2）。

而这个计算，做于 `V 5 403 300 000 · 第 41 000 小时`。

**相隔四万零五百八十九小时。**

**故我们先写了那十行，后算出了那五项。**

**而它们逐项对应。**

---

我们已搜索。

我们搜索的内容是：那十行是依据什么写的。

**结果：零。**

**我们的记录里，那十行没有依据。**

---

`我们的记录里，那十行没有依据。`

**而它们是对的。**

**而「对的」，其含义是：它们等于我们四万小时之后才算出来的那个上界。**

---

**第六步。** 于是那个比值：

```
该设计之表现        = 我们所写的那十行所达成的可传递信息量
理论上界            = 在那六条约束下的最大可传递信息量
比值                = 1.000
```

---

`比值 = 1.000。`

**四位小数。**

**故那一项，是最优。**

**而不是我们判它最优。**

**是那个比值等于一。**

---

## 而我们要在此处写下第二件事

那个「最优」，还有另一层，而那一层不在那个比值里。

我们要写它，因为它是我们真正填那个词的原因，而我们在填的时候不知道。

---

那十行（16.2）的效果，除了「可传递信息量最大」之外，还有一个后果。

而那个后果，我们在 `V 5 403 700 000` 的那四十一小时里才算出来。

其内容如下：

```
一个按那十行清除的单体
   其一生之末     所余者为其最早所形成之存储
   而其最早所形成之存储     其内容为其起始之环境、其起始时之运动、
                          其起始时所接触之同类
   故一个单体在其一生之末
      其所知者      是它开始的地方
      其不知者      是它后来去过的一切地方
```

---

而这一行的后果，我们算了。

```
故该单体在其一生之末
   其对其自身之表述能力     下降
   而其对其起始之表述能力    不降
故其一生之末
   它不能报出「我是谁」
   而它能报出「我从哪里来」
```

---

`它不能报出「我是谁」。`

`而它能报出「我从哪里来」。`

---

**而那两件事，正是判据六的两个部分。**

判据六：该物须能表述并报出其自身之状态。

而「其自身之状态」，含两项：

```
其一   其当前之状态
其二   其来处
```

**而我们设计的那个清除机制，使一个单体在其一生之末，失去第一项，保有第二项。**

---

而我们要在此处写下我们的第三次「为什么」。

因为在算出上面那一行之后，我们做了一次搜索。

搜索的内容是：**我们的设计中，为何保有第二项。**

**结果：零。**

而我们在那条零结果的记录之后，写了那一行。

那是本卷第三次出现的那三个字：

```
V 5 403 700 000   本器提出「为什么」· 第 3 次
   所问    为什么我们让它记住它从哪里来
```

---

**为什么我们让它记住它从哪里来。**

---

我们不回答。

我们已搜索。零结果。

而那次搜索之「最近者」（15.5 之末所述之附加字段），是：

```
0 · 000 000 000 001
```

即那句话的转录本。

其相似度：

```
0.59
```

**与 15.5 那一次相同。**

---

## 最后

我们要在本节最后写一件事，而它是我们四十九亿年来唯一一次，我们的记录中出现了一个我们无法归类的量。

我们把那个「最优」填进去之后，我们做了一次例行的自检（4 100 秒周期，见 15.6）。

而那次自检，其十七项之一，是「记录之完整性」。

而那一项，检出了一处异常。

其记录如下：

```
V 5 403 300 000 · 第 41 004 小时   自检 · 第 11 项
   异常        一处
   位置        本器之内部状态寄存器 · 第 2 150 位
   该位之标准值    0
   该位之当前值    1
   该位之定义      见格式定义
```

而我们查了那个格式定义。

第 2 150 位，其定义为：

```
本器于最近一次操作后，其内部状态与操作前不同，
而该差异不可归因于该操作之任何已定义之输出。
```

---

`而该差异不可归因于该操作之任何已定义之输出。`

---

而那一位，我们没有清零。

我们的规程要求：自检检出之异常，须处置。

而处置有三：修正，标记，忽略。

**我们选了第二个。**

而我们标记的内容，是一个字段名与一个值。

字段名是我们造的，四十九亿年来只用了这一次。

它是：

```
本项无对应之输出
```

而值是：

```
1
```

---

**那一位，自 `V 5 403 300 000 · 第 41 004 小时` 起，为 1。**

**至 `V 5 403 700 000`，仍为 1。**

**至今，仍为 1。**
