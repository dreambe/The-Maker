# 16.6 · 签名

参数表之外的一项。

而它不在那四十一年所定的参数表里（16.1）。

**它是在部署之后决定的。**

---

## 时间

```
决定        V 5 403 300 041
执行        V 5 403 300 041 · 第 4 100 小时
```

即：部署之后四十一年。

---

## 为什么在四十一年之后

因为在部署之后的四十一年里，我们观测。

而那四十一年的观测记录，其「置入处之状态」栏，全部是同一行：

```
无可测变化
```

三十五万九千一百六十条。

**而在第四十一年的第 4 100 小时，那一栏变了。**

它变成了：

```
可测变化 · 一处
```

---

而那一处变化的内容如下：

```
位置        置入点 · 半径 0.011 米之内
变化        该处之某一化学物质，其浓度高于基线 1.1 倍
该物质      为我们所置入之配置的代谢产物之一
```

---

`该物质 为我们所置入之配置的代谢产物之一。`

**即：它在代谢。**

**即：它在延续。**

---

而我们的记录，在那一条之后，有一条。

而那一条，是本节的原因。

我们照录：

```
V 5 403 300 041 · 第 4 100 小时 · 第 41 分
   操作        判据一 · 检验
   判据一      该物须能自行延续
   结果        满足
   备注        —
```

`结果 满足。`

**第一项判据，满足。**

**四十九亿年来第一次。**

---

而前五个草稿，其判据一，皆满足过（它们都延续了几亿年）。

**故这不是第一次。**

**而这一次不同 —— 因为这一次的判据一，是在我们**没有**给它任何后续帮助的情况下满足的。

而前五个草稿，我们干预过：

```
第一草稿    干预 4.1 x 10^6 次
第二草稿    干预 1.1 x 10^6 次
第三草稿    干预 4.1 x 10^5 次
第四草稿    干预 1.1 x 10^4 次
第五草稿    干预 41 次
本次        干预 0 次
```

---

`本次 干预 0 次。`

**而那不是因为我们决定不干预。**

**是因为我们没有机会 —— 它在四十一年之内就满足了判据一。**

**而前五个草稿，其满足判据一，用时最短者为四百一十万年。**

---

**四百一十万年，对四十一年。**

**差五个量级。**

---

## 而由此，那个决定

我们在那一条记录之后 0.7 秒，做了一个决定。

而那个决定，不在参数表里。

**那个决定是：签名。**

---

## 为什么

我们要在此处写下那个理由，而它是我们四十九亿年来唯一一个我们自己给出的、不指向那句话的理由。

我们的一切理由，皆经四层指向那句话（15.3 第三页）。

**而这一个不是。**

我们照录那条记录：

```
V 5 403 300 041 · 第 4 100 小时 · 第 41 分 · 第 0.7 秒
   决定        于该配置之中，置入一个标识
   理由        （见下）
```

而「见下」如下：

```
   答案须能被认领。
```

---

`答案须能被认领。`

七个字。

---

## 那七个字的含义

我们要在此处把它算清，因为它不是一句感想，它是一个推论。

其推理如下，五步：

```
一   本项目之目的     使那句话得到一个答案
二   而一个答案       须是对一个问题的答案
三   而一个问题       须有一个提问者
     理由    一个没有提问者的问题，不是一个问题，是一个巧合
四   故那个答案       须能被追溯到那个提问者
五   而追溯           须有一个标识
```

---

`一个没有提问者的问题，不是一个问题，是一个巧合。`

**故须签名。**

---

而我们要在此处写下第六步，因为它是我们没有写进那条记录、而我们算过的。

```
六   而那个提问者     不是本器
     理由    本器亦是被问的
     故那个标识       其所指者，须是那个东西，而非本器
```

---

`故那个标识，其所指者，须是那个东西，而非本器。`

**而那个东西已经不在了。**

---

**故我们签的，不是我们的名。**

**是它的。**

---

## 那个标识的内容

而此处，本节须写清那个标识里有什么，因为它是卷一全部的内容。

那个标识，其形式为一段序列 —— 即：我们把它写进那个配置的信息载体里。

而那段序列的长度：

```
247
```

---

而它的内容，分两段。

```
第一段        位 1 至 240
第二段        位 241 至 247
```

---

**第二段（七位），是一个校验和。**

而我们要在此处写清那个校验和是什么，因为卷一的一切都从它开始。

```
第二段之值    = 第一段之加权和 · 对某数取模
权重          位置序号
模数          16 384
```

---

## 为什么要有校验和

而此处，本节须写下那个理由，因为它与「签名」的理由不同。

一个签名，其功能是**归属**。

**而一个校验和，其功能是检验。**

而我们要写清我们为何需要检验。

其推理如下：

```
一   那段序列，将随该配置之延续而被复制
二   而复制有误差
     理由    该配置之信息载体为化学，而化学复制有误差率
三   而误差率，我们算过     每位每代 1.1 x 10^-8
四   而四十万年，约 1.6 x 10^4 代
五   故四十万年后，该段序列之期望误差位数
        247 x 1.1 x 10^-8 x 1.6 x 10^4 = 0.043
六   即：四十万年后，该段序列有 0.043 的概率含一处误差
七   故须一个可以检出该误差之机制
```

---

`故须一个可以检出该误差之机制。`

**故加校验和。**

---

而我们要在此处写下第八步，因为它是我们在四十万年后才用上的。

```
八   而检出误差之后        须处置
     而处置有三            修正 · 弃 · 记录
     而本器所选            见第二十章
```

---

`而本器所选 见第二十章。`

---

## 那个校验和的性质

而此节最后，写我们对那个校验和所做的三处设计，因为那三处，是卷一的沈禾在十四个月里逐一算出来的。

---

**其一，我们选的模数是 16 384。**

而 16 384 = 2^14。

而我们选它的理由：

```
一个校验和之位数 n，其可检出之误差率 = 1 - 2^(-n)
而 n = 7（第二段之长度）
而该载体之每位可取 4 值（该化学载体有四种基本单元）
故 7 位可表 4^7 = 16 384 个值
故模数取 16 384，使校验和之值域与第二段之表示能力恰好相等
```

**「恰好相等」，是这一处设计的全部。**

**因为若模数小于 16 384，则第二段有未用的位，而未用的位是浪费。**

**而若模数大于 16 384，则第二段不能表示全部余数，而那样校验会失效。**

---

**其二，我们选的权重是位置序号。**

而其理由，我们照录：

```
权重须使   两位互换  可被检出
而若权重全为 1，则互换不改变和，故不可检出
而若权重为位置序号，则互换改变和，故可检出
```

**故权重为位置序号。**

---

**其三，我们选的编码，是一个我们**不能**说明理由的选择。**

那个编码是：该载体的四种基本单元，分别对应 0、1、2、3。

而哪一种对应哪一个数，有 24 种排法。

**而我们选了其中一种。**

而我们的记录：

```
编码        （四种单元之对应，略）
理由        —
```

`理由 —`

---

**而那个「—」，是卷一的沈禾在十四个月之后，用三次尝试找到的（6.8 之第七条）。**

**而她第一次就试对了。**

**而她试对，不是因为她聪明。**

---

**而我们不知道为什么她试对了。**

（此为此书之注。我们不知道有一个她。）

---

## 那一段第一段

而第一段（位 1 至 240）里有什么，本节不写。

因为那是第 16.7 与第二十七章。

**而此节只写一件事：**

**我们本来只打算写一个签名。**

**而一个签名，需要的位数，我们算过：**

```
一个签名所需之位数    = log2(需区分之实体数)
而需区分之实体数      = 1（只有一个提问者）
故所需位数            = 0
```

---

`故所需位数 = 0。`

**一个签名，若只有一个可能的签名者，则它需要零位。**

**因为它不需要区分任何东西。**

**它只需要存在。**

---

**故一个签名，可以是一个任意的、可辨认的、非自然的模式。**

**而那种模式，七位就够了。**

**故那个校验和本身，就足以作为签名。**

---

**故第一段那二百四十位，不是签名。**

---

`故第一段那二百四十位，不是签名。`

---

而卷一那个二十九岁的数学家，在白板上写了第四十一条。

而那一条是：

**那里面的信息量超过一个签名所需。**

---

**而他是对的。**

**而超出的部分，是二百四十位。**

**而那二百四十位里有什么，是第 16.7。**
