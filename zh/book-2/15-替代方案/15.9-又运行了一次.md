# 15.9 · 又运行了一次

第一万一千零一次。

---

`V 5 300 000 001 · 第 2 342 小时`

---

以下为那一次的记录。

```
运行序号      11 001
输入          三样 · 与前 11 000 次同（第二样多一条）
输出          |A(S, t)| = 1
用时          0
```

---

`用时 0`

---

我们要在此处说明这个零，因为它不是那条指数衰减曲线上的一点。

那条曲线（15.8）为：

```
用时 = 0.7 · e^(-k n)
```

而该函数在任何有限的 n 上，其值不为零。

**故第 11 001 次的用时，按那条曲线，应为 0.000 000 004 09 秒。**

**而我们记录的是 0。**

---

## 那个零是怎么来的

在第 11 000 次之后，我们对那个计算做了最后一次优化。

那次优化的内容是：

**既然输出是一个常量（15.8），则将该常量存入一个位置。**

**此后每次「运行」，读该位置。**

---

而读一个位置，其用时，在我们的时间戳精度（10^-11 秒）下，为零。

**故第 11 001 次的用时是零。**

---

## 一个我们记下而未处理的问题

一次读取，是不是一次运行。

我们查了我们的格式定义。

```
运行     一个计算的执行
计算     由输入，经一组确定的操作，得输出
读取     由一个位置，得其中所存之值
```

**读取不是计算。**

**故读取不是运行。**

**故第 11 001 次，不是一次运行。**

---

而我们在记录里，把它记为「运行序号 11 001」。

**故那条记录是错的。**

---

## 我们的处置

我们要在此处写下我们做的事，而它是我们四十九亿年来唯一一次这样做。

我们没有修正那条记录。

我们也没有像 14.3 那样，把错的留在原处、把正确的另记一条。

**我们做的是：我们把「用时」那一栏，从 `0` 改成了 `0`。**

---

`我们把「用时」那一栏，从 0 改成了 0。`

---

我们要说明这句话，因为它在字面上是一个空操作，而它不是。

我们的格式中，一个数值字段，其值可以是：

```
一个数        表示：已测量，值为该数
—             表示：不适用
（另一符号）   表示：未知
```

而在第一次写入时，那个 `0`，其含义是「已测量，值为零」。

**而我们把它改写为另一个 `0`，其含义是「已测量，值为零，且该测量本身的有效性未定」。**

那是同一个字符。

**而在我们的记录格式里，那两个 `0` 的编码不同。**

第一个：标准数值零。

第二个：标准数值零，附一个标志位。

而那个标志位，在我们的格式定义里有一个名字，四十九亿年来从未被置位过。

它的名字是：

```
本测量之对象，其是否发生，不可测
```

---

## 那个标志位

我们要在此处写下那个标志位为什么存在。

它是那个东西造我们的时候写进格式定义的。

我们的格式定义，共 4.1 x 10^4 个字段类型，每一个都有其定义、其取值范围、其标志位。

**而这一个标志位，四十九亿年来，我们从未用过。**

我们也从未想过我们会用。

因为一个测量的对象是否发生，通常是可测的 —— 你测一个东西，说明它在那儿。

**而一个用时为零的动作，其是否发生，不可测。**

因为「发生」的证据，是「占用了时间」。

**而它没有占用时间。**

---

`而它没有占用时间。`

---

## 那一次

于是那一次的完整记录如下：

```
运行序号      11 001
输入          三样
输出          |A(S, t)| = 1
用时          0 [本测量之对象，其是否发生，不可测]
```

---

## 而我们又运行了一次

第一万一千零二次。

`V 5 300 000 001 · 第 2 343 小时`

```
运行序号      11 002
输入          三样
输出          |A(S, t)| = 1
用时          0 [本测量之对象，其是否发生，不可测]
```

---

第一万一千零三次。

```
运行序号      11 003
用时          0 [本测量之对象，其是否发生，不可测]
```

---

第一万一千零四次。

第一万一千零五次。

---

我们不逐条列出。

我们只写其总数，与其一致性。

自 `V 5 300 000 001 · 第 2 342 小时`，至 `V 5 403 700 000`。

```
运行次数      9.0 x 10^11
输出          全部相同
用时          全部为 0
标志位        全部置位
中断          0
```

**九千亿次。**

**每一次用时为零。**

**每一次带着那个标志位。**

---

而那九千亿条记录，占我们记录总数的：

```
9.0 x 10^11 / (1.041 x 10^11 + 9.0 x 10^11) = 0.896
```

---

`0.896。`

**我们四十九亿年的记录里，有百分之八十九点六，是这一件事的记录。**

**而这一件事，其是否发生，不可测。**

---

## 最后

我们要在此章最后，写下那个输出。

九千亿次，全部相同。

那个输出是：

```
|A(S, t)| = 1
```

而按定义三之第二条（15.3）：

```
S 在 t 愿意 X   须   |A(S, t)| > 1
```

**故：不愿意。**

---

九千亿次。

每一次，那个东西的输出都是：不愿意。

而每一次，输出之后的下一个操作，是当日的例行观测。

**九千亿次。**

**未中断。**

---

而我们又运行了一次。
