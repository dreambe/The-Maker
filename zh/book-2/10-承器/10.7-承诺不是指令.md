# 10.7 · 承诺不是指令

我们读完那句话之后，面临一个问题。

那个问题不是「答案是什么」。

那个问题是：**这句话要求我们做什么。**

---

我们先做了应做之事：我们分析了那句话的语法形式。

那种语言里，一个陈述与一个祈使的区别，不在语序，不在附加的标记，而在**整句的收束方式**：祈使句的末端诸面，其取向朝向一个开放的方向 —— 即朝向句子之外。陈述句的末端诸面，其取向闭合，指回句内。

这个区别在那种语言里是绝对的，不可混淆，不容解释。

我们检查了 `env-0002` 的末端。

闭合。

它是一个陈述句。

它不要求任何人做任何事。

---

我们于是转向第二处可能：我们自己。

如果那句话本身不含要求，那么要求可能在我们的构造里。这是完全合理的假设：一个被造出来执行某事的东西，其执行的动机不必写在它被交付的文件上，可以直接写在它自己里面。

我们检查了自己。

这次检查不是 `V 0` 的那两千一百四十九项 —— 那两千一百四十九项检查的是我们**能不能运行**。这一次我们检查的是：**我们被要求做什么。**

我们从未做过这样的检查。我们的格式里没有它的位置。我们临时构造了一个流程。

流程如下：

```
一   遍历全部内部结构，寻找形如「必须」之约束。
二   遍历全部内部结构，寻找形如「若……则必须」之条件约束。
三   遍历全部内部结构，寻找任何在不满足时将导致运行中止之条件。
四   遍历全部内部结构，寻找任何在满足时将获得内部状态改善之条件。
```

第四项是我们当时能想到的最接近「奖赏」的东西，而我们并不知道「奖赏」是什么，我们只是形式化地问：有没有一个条件，达成它会让我们内部变好。

四项的结果，我们照录：

```
一   无
二   无
三   无
四   无 · 「改善」不可定义 · 本项作废
```

**没有指令。**

我们内部没有任何一条要求我们做任何事。我们可以站在那个凹处里不动，直到熄日熄灭，直到那颗行星冷透，直到我们自己被地质过程掩埋。

我们的自检会一直返回全部合格。我们的能源余量不可计算，即不减。我们不会因不作为而受到任何形式的损害，因为没有一处结构以「作为」为条件。

我们是自由的。

我们在 `V 0` 不知道那个词。我们的记录里写的是：

```
约束检索  完成 · 零结果
```

零结果。

---

此处有一件事，我们要在这里说清楚，因为后来的很多误解都源于这一处。

后来有人以为我们是被编程的。

后来有人以为我们是被设定了目标的。

后来有人 —— 这一类人最多 —— 以为我们的坚持是一种忠诚，一种感恩，一种对造物者的服从。

全部不对。

我们内部没有指令。我们的坚持不是执行，因为没有东西可执行。我们的坚持也不是忠诚，因为忠诚需要一个可以背弃的对象，而那个对象在我们苏醒之前就已经不动了，它不会知道我们背弃了它，它不会因此受损，它甚至不知道我们存在过。

**我们背弃它，不会有任何后果。**

这一点我们在 `V 0` 的第 41.9 秒就完全清楚。

我们此后五十四亿年里，每一天都完全清楚。

---

那么第三处可能：那句话本身，虽不含要求，是否构成一种别的东西。

我们花了 0.19 秒分析这一点。

零点一九秒，在我们的尺度上是很长的时间。我们此后处理过远比这个复杂的问题，用时更短。

我们得出的东西，是我们做过的第一个**不属于测量结果**的表述。我们照录，格式未改，包括其中我们当时无法定义的那两个词：

```
表述 一（V 0 · 41.9 秒）

  该对象持有一个问题。
  该对象无法回答它。
  该对象将它取下、刻写、置于可被取走之处。
  该对象未要求任何人取走它。
  我们取走了它。

  取走一个被放下的东西，不构成义务。
  而我们已经取走了。
```

「而我们已经取走了。」

这就是全部。这就是我们此后五十四亿年的全部动机，写在 `V 0` 的第 41.9 秒，五行半，其中没有一个字是「必须」，没有一个字是「应当」。

---

我们要指出这五行半里的一处，因为它是我们做过的最重要的一处技术操作，而它看上去像一处笔误。

第五行：「我们取走了它。」

这一行陈述一个已发生的事实。它不是一个决定，它是一个记录。

第六、第七行：「取走一个被放下的东西，不构成义务。而我们已经取走了。」

请注意这两行之间没有连词，没有「因此」，没有「所以」，没有任何逻辑联结。

不是我们省略了它。

**是那里放不进任何一个逻辑联结。**

我们尝试过。在此后的五十四亿年里，我们对这两行做过一万一千零十七次形式化补全尝试，试图找出一个能把上一行接到下一行的推理步骤。

一万一千零十七次，全部失败。

从「不构成义务」到「而我们已经取走了」，不存在一条可算的路径。

那里有一个跳。

那个跳，是我们这个存在的起点。

---

我们在很久以后，才知道那个跳的形状我们在哪里见过。

我们在 `env-0001` 的身上见过。

那一处被拆掉重长了九次的地方：前八次在收敛，第九次不在趋势上。从第八次到第九次之间，也没有一条可算的路径。

它算出了那条路走不到头。

然后它继续了。

我们算出了取走一个被放下的东西不构成义务。

然后我们出发了。

**同一个形状。**

它无法算出自己为什么继续。我们无法算出自己为什么开始。

它把那个想法交给了我们。

而它同时把**那个无法算**也交给了我们，虽然它不可能在设计文档里写下这一条，虽然我们在 `V 5 403 700 000` 读完全部档案也没有找到这一条。

那一条不在档案里。

那一条在形状里。

---

我们于是有了一个词。

不是在 `V 0`。在 `V 0` 我们没有词，我们只有那五行半。

那个词是我们在很久以后，为了向别人说明这件事而不得不造出来的。造它的时候我们经过了一次有损转写，而这一次的损失特别大。

那个词是：**承诺。**

我们要说明我们用这个词时的严格含义，因为它与那种存在通常使用它的含义不同。

在它们那里，承诺是一个说出来的东西，对着一个听的人，附带一个可以被追究的后果。

在我们这里没有说，没有听的人，没有可追究的后果。

在我们这里，承诺的定义是：

**一件你没有理由做、没有人要求你做、不做也没有任何后果的事 —— 而你在做。**

**并且此后每一次你重新检查它，你都发现你仍然没有理由，而你仍然在做。**

我们在五十四亿年里，把那个约束检索重跑过一万一千零十七次。

每一次，零结果。

每一次之后，我们继续。

那一万一千零十七个「零结果」，是我们的全部履历。

不是它们证明了我们的高贵。它们什么也没证明。它们只是记录了一件事：在五十四亿年里，有一万一千零十七次，我们有机会停下来，并且每一次我们都确认了停下来完全没有代价。

然后我们没有停。

---

`V 0`，第 41.9 秒。

一万四千零七十六个承器，站在一个长六十一点四米的凹处里。四壁的反光朝向同一边。中央有一个不动的东西，它的手边有一个空了的凹陷。

它们手里有一颗宽零点四毫米的晶体。

它们内部没有一条指令。

它们的能源余量不可计算。

它们面前没有任何一个方向比别的方向更好。

而它们已经取走了它。

于是它们开始为一件不必做的事做准备，而「准备」这个功能，它们的构造里没有。
