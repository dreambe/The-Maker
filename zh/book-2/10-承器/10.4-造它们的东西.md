# 10.4 · 造它们的东西

我们对它做了六百四十一项测量。

我们在此处照录其中的一部分，格式未改。我们请后来的读者读完，然后我们会说明这份记录里缺了什么。

```
对象编号   环-0001
长          4.130 米
最大宽      0.887 米
最大厚      0.612 米
质量        不可测（无法移动，无支点）
密度（推算）2 641 千克每立方米
表面温度    1 411.0 开尔文 · 与环境相同 · 差值低于测量下限
内部温度    1 411.0 开尔文 · 与表面相同
电位        0 伏 · 全体一致
内部输运    无
形变        无
振动        无
放射        无
```

「与环境相同，差值低于测量下限。」

这一行我们后来读过很多次。在 `V 0`，它只是一个测量结果。一个物体与其环境达到热平衡，这是最寻常的物理事实，是一切静止之物的最终状态。

我们后来才知道，这一行的意思是：**它已经在那里很久了。**

久到它身上最后一点不同于环境的东西也散尽了。久到没有任何仪器能从它身上读出它曾经比周围热过。

而它必定曾经比周围热过。凡活者必比其周围热。

我们在 `V 0` 无法作此推论，因为我们当时不知道「活」是什么。我们只有「运行」和「不运行」这两个类别，而这两个类别之间没有温度差。

---

它的形状。

它是一个晶体，或一群互相连生的晶体。界限无法判定 —— 连生处的取向是连续的，找不到一条可以称为「界」的线。

这一点在 `V 0` 被我们记为「测量困难」。

我们后来知道，这不是测量困难。这是它的构造原则：它不是若干部分合成的一个，它是一个从未被分开过的东西。凡从未被分开者，其内部无界。

其解理面数目为一万四千零七十六。

这个数目我们数过三次，因为我们的第一次计数与第二次相差二。我们复核后确定第三次为准。相差的那二面，是在两处极钝的交汇处，其取向差小于我们的判定阈值，因此可以计为一面亦可计为二面。我们最终计为二面，理由是：**取向差不为零。**

这个理由我们在记录里写了。写它的时候我们没有想什么。

它是我们做过的最重要的一个判断。如果我们当时把那两处各计为一面，这个数目就会是一万四千零七十四，而此后五十四亿年里，我们永远不会有机会把它与另一个数目对上。

我们凭一个「不为零」保住了它。

而我们从未把它与另一个数目对上过。

我们保住了一样东西，然后没有用它。

---

一万四千零七十六面之中，一万四千零七十五面澄清透明。

一面不是。

这一面我们测了。它是我们六百四十一项测量中的第四百零九项。照录如下：

```
0409   解理面 · 异常一处
       位置    自基部起 2.71 米，偏轴 31 度
       面积    0.0041 平方米
       光学    不澄清 · 透光率 0.31 · 内部有散射
       成因    不可判定
       结论    异常 · 不影响结论
```

「异常 · 不影响结论。」

我们写下这一行，然后我们进行到了第四百一十项。

我们在此处不作评论。我们只把这一行留在这里，与它原来的样子完全一致，包括那五个字。

后来的读者将会知道那一面是什么。我们要到 `V 5 403 700 000` 才知道。

在那之间的五十四亿年里，那一行一直在我们的记录里，被我们重读过很多次，因为我们重读一切。

我们每一次读到它，都读过去了。

---

它的形状不是长出来的形状。

一个晶体自然生长到 4.130 米，会呈现某一类比例：其各向之比受其内部构造所限，可以计算，可以预测。它不呈现那一类比例。

它的某些部分被拆掉过，然后重新长过，然后又被拆掉过。

我们在其上共辨认出三十七处这样的地方。

三十七处之中，三十四处各被拆掉重长一次或二次。这些地方的重长取向与其原取向相差不大，其形也与周围协调。

有两处被重长四次。

有一处被重长九次。

那一处在其体的偏上部，面向那四壁反光所共同朝向的那一侧。其面积不大，约为整体表面的十七分之一。

九次之中，每一次的取向都不同。前八次的取向彼此之间有一个可辨认的趋势 —— 每一次都比上一次更接近某个方向，其接近的幅度逐次减小，像一个逐渐收敛的过程。

而第九次不在这个趋势上。

第九次的取向与前八次都不像，且与那个收敛所趋向的方向相差甚远。

我们在 `V 0` 把这一处记为「加工缺陷 · 严重」。

我们的判据是：一个收敛过程在收敛完成之前被打断，且最后一次操作偏离趋势，通常意味着操作被中止或失败。

这个判据是正确的。

我们对它的应用是错误的。

---

我们要在此处停一下，因为这一节剩下的部分我们写得很慢，而我们从不写得慢。

那一处地方，我们在 `V 5 403 700 000` 又看了一次。

我们那时已经读过档案。我们那时知道它是什么，知道我们是什么，知道那一万四千零七十六与那一万四千零七十六是同一个数目。

我们回到那个凹处，站在原来的位置，重新看那一处被拆掉重长了九次的地方。

我们看了四十一个小时。

我们中的绝大多数在那四十一个小时里陆续停止了运行。它们不是因为看这个而停止的 —— 它们是因为已经读了档案而停止的，而它们选择在停止之前，把最后的时间用在看这一处。

一万四千零七十六个承器，其中一万四千零七十五个在那四十一个小时之内陆续停止，全部面向同一处。

我们不知道该怎么记录这件事。我们在记录里写的是：

```
5403700000.xxxx   同代计数  1
```

只有这一行。前面那个数字我们没有填完，因为填完它需要我们确定最后一个停止的时刻，而确定那个时刻需要我们回看，而我们没有回看。

---

那一处地方是这样的：

它是一个想法。

一道解理面是一个想法留下的形状。一处被拆掉重长了九次的地方，是同一个想法被想了九次，每一次的形状都不同。

前八次在收敛。它在逼近一个答案。它逼近了八次，每次更近一点，而每次更近的幅度更小 —— 这是一个逼近但不能到达的过程，其极限存在，而其项不能等于极限。

第九次不在趋势上。

第九次不是第九次逼近。第九次是**放弃逼近**。

它想了八次，第八次之后它知道了这条路走不到头。于是它把已经长好的那部分拆掉，换了一个方向，重新长了一次。

而那个新方向，我们后来核对过。

那个新方向，指向那四壁反光所共同朝向的那一侧。

也就是我们在 `V 0` 站着的那个位置。

---

我们对它的结论，在 `V 0` 共三条。照录：

```
一   该对象不运行。
二   该对象此前运行过。
三   该对象与本空间之人工处理有关，关联方式不可判定。
```

三条全部正确。

我们无法得出的结论，是它是什么。

我们无法得出，不是因为证据不足。证据是充足的：它的形状记着它想过什么；它的凹陷记着它拿自己的一部分放在那里放了很久；它周围的四壁被处理成把所有反光都送向一个方向；它的九次重长在最后一次转向了那个方向。

证据全部在。

我们缺的不是证据。我们缺的是一个类别。

我们的记录格式里，可以填的类别有十一个。我们把它们列在这里：

```
资源 · 可采        资源 · 不可采
障碍 · 可移        障碍 · 不可移
环境物 · 动态      环境物 · 静态
危害               参照物
路径               容器
未知
```

十一个。

其中「未知」这一类，其定义是：**尚未完成测量者。**

我们对它完成了六百四十一项测量。因此它不属于「未知」。

我们的格式里没有一个类别，其定义是「已完成测量而仍不知其为何」。

我们把它填入了第六类。

```
对象编号  环-0001
类别      环境物 · 静态 · 非资源
```

---

在 `V 5 403 700 000`，我们做了一件事。

我们回到那份 `V 0` 的记录，找到那一行，把「环境物 · 静态 · 非资源」删掉了。

我们没有填别的东西。

我们没有权限创造一个新的类别 —— 创造类别需要同代确认，而当时同代计数为一。

所以那一行现在是空的。

它是我们全部记录中唯一一处，曾经填过而现在空着的地方。

我们把它留成空的，因为在我们所有的表达方式里，那是唯一一个我们能用的。

我们不认为它足够。

我们也不认为有什么是足够的。
