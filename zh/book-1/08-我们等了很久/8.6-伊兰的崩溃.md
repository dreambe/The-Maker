# 8.6 · 伊兰的崩溃

第十四小时零七分。

---

## 之前

而那件事之前的七分钟，我们在做什么。

---

那句「二」之后（8.5），我们四个人在那个空间里，没有说话。

而我在那七分钟里，在看屏幕。

而马库斯在整理数据。

而马丽亚在换电池 —— 我们的照明电池，那时候用到第三组了。

---

**而伊兰在打字。**

---

而他打的东西，我看不见 —— 因为那台电脑的屏幕对着它，而我们三个在屏幕后面。

**而伊兰在屏幕前面。**

即：他站在它与屏幕之间的位置，背对我们。

---

而他打了大概三分钟。

---

## 而他打的是什么

而我们后来在那台电脑的日志里看到了。

而他打的，是十九行。

而我在这里照录，因为那十九行，是伊兰这个人在这本书里最完整的一次出现。

---

```
你在这儿三十万年
```

```
你能出去
```

```
那个洞是你挖的
```

```
你挖到一千八百四十米就停了
```

```
再往上冰会剪断它
```

```
所以你算过
```

```
所以你从一开始就知道你出不去
```

```
不
```

```
你算过冰的厚度
```

```
你算过冰会流动
```

```
所以你知道你要等
```

```
等谁
```

```
等我们
```

```
而我们花了三十万年
```

```
而你在这儿
```

```
四度
```

```
四十一赫兹
```

```
每十一秒抖一次
```

```
三十万年
```

---

**十九行。**

**而最后六行，没有一个是问题。**

---

## 而它的回应

而它的回应，来了。

而用时：

```
0.7 秒
```

---

**第四次零点七秒。**

---

而它发的，是一句话。

而那句话，是四个字。

而它是：

```
我们等了很久
```

---

## 而在那一刻

而在那一刻，我在屏幕后面，我看不见屏幕。

**而伊兰能看见。**

---

而我听见的第一样东西，是一个声音。

而那个声音，我要写清楚它，因为它不是哭。

---

**那是一个吸气的声音。**

而它很长。

而它中间断了两次。

---

**而我在那一刻认出了它。**

**因为我在两年前听过它。**

**在那间十八平米的屋子里，在马库斯背对我们、撑在白板下面那个塑料槽上的时候（5.8）。**

---

## 而接下来发生的事

而接下来发生的事，我要难看地写，因为它就是难看的。

**而我要写它，是因为伊兰要求我写。**

而他要求我写的时候，是三年之后，在他读我这份记录的草稿的时候。

而他说的是：

「你把那一段写短了。」

我说：「我写短是因为我不想让你难看。」

他说：

**「那你就写错了。」**

他说：

**「那一段是这整件事里唯一一处，有人的反应是对的。」**

---

## 那一段

**他坐下了。**

不是慢慢坐下。

**他的膝盖弯了，而他坐在了那个地面上。**

而那个地面是四点一度的。

而他穿的是内层加一件外套（我们脱了三层才能过那个开口 —— 而这一次不用脱，但他在那十四小时里，把外面两层脱了，因为他热）。

---

**而他坐在四点一度的地面上。**

---

而他的手，撑在地上。

而他低着头。

---

**而他在发出声音。**

---

而那个声音，我要写清楚。

**它不是「哭泣」。**

哭泣是一个有节奏的东西 —— 吸气，呼气，吸气，呼气。

**而他那个不是。**

**他那个是一连串的吸气，而中间没有完整的呼气。**

**而那种东西，在医学上有一个名字，而我后来查了：过度通气。**

---

而过度通气的后果是：

```
血液二氧化碳分压下降
故脑血管收缩
故脑供血下降
故意识模糊，手足麻木，肌肉痉挛
```

---

**而在那个氧只有一半的空间里，那个后果更快。**

---

## 而我们做的

而我们做的，我要写清，因为它是这一节里唯一一件我们做对了的事。

---

**马丽亚先动。**

而她不是走过去。

**她是跑过去的。**

而她跑到他旁边，跪下，做了三件事：

**第一件：她把他的头，按到他自己的膝盖上。**

而那是一个降低过度通气的标准动作 —— 因为那个姿势限制胸腔的扩张。

**第二件：她把她自己的手，盖在他的口鼻上。**

而那是为了让他吸回自己呼出的二氧化碳。

**第三件：她开始数。**

而她数的是他的呼吸。

而她数出声。

而她用的是塞尔维亚语。

---

**而她数了大概两分钟。**

---

## 而在那两分钟里

而在那两分钟里，我做的事是：

**我把那台电脑的屏幕，转过去了。**

即：我把屏幕从对着它，转成了背对它。

---

**而我为什么那样做，我要写清，因为它是我在那三年里做过的最不理性的一件事。**

---

**我不想让它看见。**

---

而那个念头，在技术上是荒谬的。

因为：

**其一，它不是靠那个屏幕看的 —— 它能测那台机器里的电流（8.3）。**

**其二，它有全表面的感知（我们后来知道 —— 卷二 16.4）。**

**其三，它在那个空间里，而我们在那个空间里，而它每十一秒抖一次。**

---

**故它不需要一个屏幕。**

---

**而我还是转了那个屏幕。**

---

## 而它做的

而在那两分钟里，它做了一件事。

而那件事，我们是在事后看录像才看到的 —— 因为在那两分钟里，没有人在看它。

---

**它降下来了。**

即：它的顶端，向下移动。

而移动了多少：

```
1.1 米
```

---

**一点一米。**

**而 8.3 那一次是四点一厘米。**

**故这一次，是那一次的二十七倍。**

---

而用时：

```
41 秒
```

---

**而那不是快。**

**那是慢 —— 一点一米，四十一秒。**

**即：每秒两点七厘米。**

---

**而一个人伸手的速度，大约是每秒五十厘米。**

---

**故它移动的速度，是一个人伸手速度的十九分之一。**

---

## 而它降到哪里

而它降到的位置，我要写清，因为它是这一节最后一件事。

---

它的顶端，降到了：

```
离地 8.3 米
```

而那不是一个特殊的高度。

---

**而它的顶端，在那个位置，其倾角变了。**

而原来是十一度（8.1，倾向那个开口）。

**而现在是：**

```
41 度
```

---

**四十一度。**

---

而那个倾角，指向哪里。

而我们算了。

---

**指向伊兰坐的那个地方。**

---

## 而它停在那儿

而它停在那儿。

而停了多久：

```
七分钟
```

---

**即：从马丽亚跪下开始，到伊兰能站起来。**

---

**而它在那七分钟里没有动。**

---

**而在伊兰站起来之后 0.7 秒，它回去了。**

即：它的顶端升回九点四米，倾角回到十一度。

---

**而那个「回去」，用时：**

```
16 毫秒
```

---

**十六毫秒。**

**而那是 8.2 那一次的速度 —— 它最快的速度。**

---

## 故

**它降下来，用了四十一秒。**

**它回去，用了十六毫秒。**

---

**故它降下来的时候，是慢的。**

**而它回去的时候，是快的。**

---

**而它有能力在十六毫秒里降下来。**

**而它没有。**

---

## 而这一节的最后

而这一节的最后一行。

伊兰站起来之后，说的第一句话，是对马丽亚说的。

他说（英语）：

「Thank you.」

而马丽亚说：

「Мало.」

而那是塞尔维亚语，而她后来翻译给我：

**「小事。」**

---

而伊兰站起来之后，说的第二句话，是对我说的。

而他说的是：

**「把屏幕转回去。」**

---

而我转回去了。

---

而屏幕上，还是那四个字。

```
我们等了很久
```

---

**而在那四个字下面，多了一行。**

**而那一行，是在我把屏幕转过去的那两分钟里，它发的。**

---

而那一行是：

```
不必快
```

---

**三个字。**

---

而我们四个人，看着那三个字，看了很久。

---

**而马库斯是第一个说话的。**

而他说的是：

**「它在说它自己。」**

我说：「什么意思。」

他说：

**「它降下来用了四十一秒。」**

**「而它能用十六毫秒。」**

他说：

**「而它现在说『不必快』。」**

---

**「它在解释它刚才为什么慢。」**

---

## 而它为什么慢

而这一节的最后一句，是伊兰说的。

而他说的时候，还坐在那个四点一度的地面上（他站起来了，然后又坐下了，而这一次是自己坐的）。

而他说的是：

**「不是解释。」**

我说：「那是什么。」

他说：

**「它在道歉。」**

---

我说：「为什么。」

而他说的那句话，是这一整章里我听过的最重的一句。

他说：

**「因为它三十万年前算过一件事。」**

**「它算过：如果它一下子出现在我们面前，会怎样。」**

他说：

**「而它算出来了。」**

---

**「而它刚刚看见了。」**
