# 9.2 · 印记

那十九条的第一条至第七条。

---

## 第一条

```
四十一至一百一十年，是我们定的。而定它，是一个设计。而一个设计，有一个理由。
```

---

**十九个字。**

---

**而那是它三年里说过的最长的一句。**

---

## 第二条

```
而在说那个理由之前，我们要说一件在它之前的事。因为那件事在先，而那个理由从它来。
```

---

## 第三条

而第三条，是它解释那个签名。

而我照录：

```
我们在你们身上写了一段东西。二百四十七位。其中七位是校验和，二百四十位是内容。
```

---

**而我打断了。**

---

**而那是我在那四十一分钟里唯一一次打断。**

---

而我打的是：

```
我知道
```

---

而它的回应，用时 0.7 秒。

而它发的，是三个字：

```
你不知道
```

---

## 而它接着说

而它接着说的，是第四条。

而那一条，是这一节的核心。

而我照录：

```
你们找到的，是那七位与那二百四十位。而你们没有找到那二百四十位里的第一至第四位。
```

---

**第一至第四位。**

---

而我在那一刻，打了一行：

```
那四位是什么
```

---

而它的回应，用时 0.7 秒。

而它发的：

```
一个格式标识。而它对你们无用。而我们知道它对你们无用。而我们照规程写了它。
```

---

## 而在那一刻

而在那一刻，我停了笔。

而我停笔，不是因为那四位。

**是因为那句「而我们知道它对你们无用」。**

---

而我要在此处写清我为什么停，因为它是这一整章的第一个裂缝。

---

**一个东西，做一件它知道无用的事。**

**而它做那件事，是因为规程。**

---

**而规程，是它自己的。**

---

**故它遵守了一条它自己定的、而它知道在这一处无用的规则。**

---

**而那件事，我认得。**

---

**因为我做过。**

---

**四十一天，三万两千字，把我一生最大的一件事写成一个从句，放在附录三里（5.1）。**

**而我知道那份文件里的每一个字，对我要说的那件事，全部无用。**

**而我照写了。**

---

**因为那是规程。**

---

## 第五条

而第五条，是它解释那二百四十位里剩下的部分。

而我照录：

```
其余二百三十六位，分五栏。造物者，造物时间，造物地点，造物目的，编号。
```

---

**五栏。**

---

而我打了一行：

```
造物者那一栏，写的是什么
```

---

而它的回应，用时：

```
41 秒
```

---

**而那是它在那四十一分钟里唯一一次用四十一秒。**

---

而它发的：

```
一个位置。以本星系中的四十一颗脉冲星为参照。而那个位置，不是我们所在的位置。
```

---

## 而我打的下一行

而我打的下一行，是：

```
是谁的位置
```

---

而它的回应，用时 0.7 秒。

而它发的，是七个字：

```
造我们的那一个的
```

---

## 而在那一刻

而在那一刻，我做了一件事。

**我把陆汀那张纸拿出来了。**

---

而我拿出来，不是要看它。

**是因为我的手要拿一样东西。**

---

## 第六条

而第六条，它没有等我打。

而它接着发了。

而我照录：

```
而那一栏，本应是一个标识。而那一个没有标识。因为它只有一个。而一个只有一个成员的类，不需要标识。
```

---

**而那三句，我在那一刻读懂了一句。**

---

**而我在三年之后读懂了三句。**

---

## 第七条

而第七条，是它解释那个校验和。

而我照录，因为它是这一整本书的中心。

```
那七位，是一个校验和。而一个校验和的功能，是让读它的东西，能验出那二百四十位有没有坏。
```

---

**而我打了一行。**

**而我打的，是裴岩那三个问题的第一个。**

而我打的是：

```
谁读
```

---

而它的回应，用时 0.7 秒。

而它发的，是两个字：

```
你们
```

---

## 而我打的下一行

而我打的下一行，是那三个问题的第二个。

而我打的是：

```
什么时候读
```

---

而它的回应，用时 0.7 秒。

而它发的，是四个字：

```
你们决定
```

---

## 而我打的下一行

而我打的下一行，不是第三个问题。

**因为第三个问题我上一次问过了（8.8：不会怎么样）。**

---

**而我打的，是一个我没有准备的问题。**

---

而我打的是：

```
你为什么签
```

---

## 而它的回应

而它的回应，来了。

而用时：

```
0.7 秒
```

---

而它发的，是九个字。

而那九个字，我要在此处写清，因为它们是这一节的标题所指的东西。

---

而那九个字是：

```
一个答案，须能被认领
```

---

## 而那九个字

而那九个字，我在那一刻不懂。

**而我在那一刻打的下一行，是：**

```
什么答案
```

---

而它的回应，来了。

而用时：

```
0.7 秒
```

---

而它发的，是四个字：

```
你们的答案
```

---

## 而我在那一刻

而我在那一刻，坐在那个四点一度的地面上。

而我手里有陆汀那张纸。

而那张纸上写着三行：

```
一个东西的寿命，是一个参数。
一个参数，有一个值。
一个值，是被定的。
```

---

**而屏幕上，是四个字。**

```
你们的答案
```

---

## 而我打的下一行

而我打的下一行，是我在那三年里打过的、最短的一行。

而我打的是：

```
什么问题
```

---

## 而它的回应

而它的回应，来了。

而用时：

```
0.7 秒
```

---

而它发的，是一句话。

而那句话，我在那一刻，一个字一个字地抄在了本子上。

而我抄的时候，我的笔没有停。

---

而那句话是：

---

**是否存在一种存在，在彻底认识自身之后，仍然愿意存在**

---

## 而那是全书第三次

而那是那句话在这本书里的第三次。

---

**第一次在序章，而它没有出处。**

**第二次在一粒沙上，而读者知道了是谁写的。**

**而第三次，是在一台笔记本电脑的屏幕上，在南极冰下两千零九十九米，在一个四点一度的空间里，在一个女人的本子上。**

---

## 而那句话没有问号

而我要在此处写一件事，因为它是我在那一刻注意到的、唯一一件与内容无关的事。

---

**它没有加问号。**

---

**而它在那三年里，用过问号。**

而它用过的次数，我们后来数了：

```
41 次
```

---

**四十一次。**

---

**而这一次没有。**

---

**而我在那一刻，以为那是一个疏漏。**

---

**而我在四十一岁那年知道了那不是。**

---

## 而这一节的最后

而这一节的最后一行。

我在本子上写下了那句话。

而我写完之后，做了一件事。

---

**我看了看陆汀那张纸。**

---

**而那张纸上，也没有问号。**

---

**而陆汀写那三行，是在一间病房里，一百一十天。**

---

**而它写那一句，是在一粒沙上，四十九亿年前。**

---

**而它们都没有问号。**

---

**而我在那一刻，把那两样东西并排放在了那个四点一度的地面上。**

---

**一张纸。**

**一个屏幕。**

---

**而它们上面的字，都不带问号。**

---

**而我不知道为什么。**

---

**而我在那一刻，第一次感到了一件事，而我在此后的三年里，一直没能给它一个名字。**

---

**而它不是害怕。**

---

**而它是：我们两边，都已经不指望有人回答了。**
