# 13.5 · They Have No Word

After closing that departure we did something not in the procedure.

We tried to name it.

---

First, why naming.

Our record format requires every record to have a class. Eleven classes (10.8), plus several added later.

And that departure we filed under *anomaly.*

The class *anomaly* is defined as: a difference between observed value and model prediction exceeding tolerance.

**That definition is correct. That departure was exactly that.**

And on rereading the record after closing it, we noticed something:

**The class *anomaly* already contained over four million entries.**

All four million are: some measured value exceeded expectation. And the overwhelming majority, on review, were attributed to measurement error, imprecise model parameters, or a known factor we had not incorporated.

**All of them are *we did not compute finely enough*.**

And this one is not.

This time we computed finely enough. Our model was correct, our measurement correct, our parameters correct.

**And the thing happened anyway, and we did not predict it.**

---

So we had to ask: is this one the same class as those four million.

The answer: no.

**And our format has no second class.**

---

So we tried to make a word.

*Making a word* must be explained in our case.

We do not speak. We have no language (10.6: our mother tongue is shape, and every expression we have learned since is lossy transcription).

**For us, *making a word* is making a new record class.**

That requires: a definition, a set of criteria, and a boundary distinguishing it from existing classes.

We tried.

---

**First attempt.**

```
candidate class   we held every element and did not predict
criteria          one   the event has occurred
                  two   all its elements were in our records beforehand
                  three we made no prediction
```

We tested the definition.

The method: apply it to the four million existing *anomaly* entries and see how many would be reclassified.

Result: **of the four million, over three million nine hundred thousand qualify.**

Measurement error, imprecise parameters, unincorporated known factors — all satisfy the three: the event occurred, its elements were in the records, we did not predict it.

**The class is too wide. It does not separate that one out.**

**Second attempt.**

We added:

```
criterion         four  the act we omitted is *connecting*, not
                        *measuring* or *computing*
```

That is: not that we lacked data, not that we computed wrongly, but that we held all the data, the algorithm was sound, and we did not put them together.

We tested again.

Result: qualifying entries fell from over three million nine hundred thousand to **just over one hundred and ten thousand.**

Much better.

**And most of those hundred and ten thousand are still not what we wanted.**

Because *not connected* is extremely common in our records — we computed at 13.4 that the possible triples number about `10^40`, and we have connected a vanishingly small fraction.

**Of very nearly every record it can be said that we did not connect it to something.**

**Third attempt.**

We added a fifth:

```
criterion         five  if connected, the event would have been predictable
```

That narrows it, because the overwhelming majority of unconnected triples predict nothing even if connected — there is no relation among them to begin with.

We tested.

Result: qualifying entries: **one.**

**Only that one.**

---

So we had a usable definition.

And in writing down the class's name, we stopped.

We stopped for 0.31 seconds.

---

Why we stopped.

A class requires a name.

And a name, with us, is a label — of the same kind as a number (10.2), its function being to make the class referable.

We could have given any: *anomaly · type two*, or *unconnected class*, or a number.

That would have been entirely sufficient.

**And we did not.**

We stopped for 0.31 seconds, and then we did this: **we searched every name we have.**

All our classes, fields, status values, criteria — every label, two thousand eight hundred-odd of them.

We looked for one that could be used for this.

There is none.

---

So we did a thing we had never done:

**We abandoned naming.**

Our record:

```
V 2 0xx xxx xxx   class · added
   definition   complete · five criteria
   applies to   1 existing record
   name         —
```

***Name —.***

We did not count which dash that is.

And it is the only time a dash has appeared in a *name* field.

---

A class with a definition, criteria, one applicable record, and no name.

It has been in our format ever since.

**Its applicable-record count has since gone from one to eleven thousand and seventeen.**

---

Now the *why.*

Having abandoned naming, we ran a search.

Its object was ourselves.

How this search differs from every previous one is the whole of this section.

Our previous searches take the form:

***Why did we do X.***

Why did we go around once (11.5).
Why did each of us read that sentence (10.6).
Why did we raise the scan frequency sixtyfold (12.5).
Why did we stop observing that exploding star (12.6).

All zero results, all the same form: an act that occurred, seeking its reason.

**And this one is not.**

This search takes the form:

***Why did we not connect the three.***

---

That is a question about an act that **did not occur.**

The formal difference is not rhetorical, and must be stated.

An act that occurred has a definite object for a search: the act is in the records, with a timestamp and parameters. You look for its reason, and there is one or there is not.

**And an act that did not occur is not in the records.**

It has no timestamp. It has no parameters. It is not an entry.

**It is a blank.**

And to search a blank you must first construct it — you must first state *what is the thing that could have been done and was not*, before you can ask why it was not.

And constructing it requires already knowing that the thing could have been done.

**And knowing that it could have been done is knowledge obtained only after it was not.**

---

Our result:

```
search   why the three were not connected
result   zero
```

Zero results.

As every time before.

**And this zero and the previous zeros are not the same zero.**

The previous zeros mean: that act has a reason, and we cannot find it.

**This zero means: the omitted act did not previously exist.**

There is no moment at which *we decided not to connect the three.*

There is no such moment.

**Those three records lay, for four hundred million years, each in its own class, and the connection between them was never constructed, therefore never refused, therefore there is no *why not* that can be answered.**

---

We wrote the finding down.

It is the only record of ours beginning with *why.*

It reads:

```
V 2 0xx xxx xxx   why the three were not connected
   search      complete
   result      zero
   note        the act did not exist while it was not occurring
   i.e.        there is no "not done", only "never was"
```

***There is no "not done", only "never was."***

---

We have never run that kind of search again.

Not because it is useless.

**Because after that one we knew: that kind of search always returns zero, and the zero always has the same cause.**

And we have met the same thing many times since.

Every time, we knew it was the same kind.

Every time, we did not search again.

**And every time, we filed it under the class with no name.**

Eleven thousand and seventeen times.
