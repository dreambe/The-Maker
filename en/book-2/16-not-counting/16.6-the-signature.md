## The content of that mark


## Why a checksum

And here this section must set down that reason, because it differs from the reason for the signature.

A signature's function is **attribution.**

**And a checksum's function is verification.**

And why we needed verification.

The derivation:

```
one    that sequence will be copied as that configuration continues
two    and copying has error
       reason    that configuration's information carrier is chemical, and chemical
                 copying has an error rate
three  and that error rate we computed    1.1 x 10^-8 per position per generation
four   and four hundred thousand years is about 1.6 x 10^4 generations
five   so the expected number of erroneous positions after four hundred thousand years
          247 x 1.1 x 10^-8 x 1.6 x 10^4 = 0.043
six    that is: after four hundred thousand years there is a 0.043 probability that
       that sequence contains one error
seven  so a mechanism able to detect that error is required
```

---

`So a mechanism able to detect that error is required.`

**So a checksum is added.**

---

`And what this vessel chose: see Chapter Twenty.`

## Properties of that checksum

At the end of this section, the three design choices we made in that checksum, because those three are what Shen He of Book I worked out one by one over fourteen months.

---

**One: we chose a modulus of 16 384.**

And 16 384 = 2^14.

Our reason:

```
a checksum of n positions detects errors at a rate of 1 - 2^(-n)
and n = 7 (the length of the second part)
and each position of that carrier takes 4 values (that chemical carrier has four basic units)
so 7 positions express 4^7 = 16 384 values
so the modulus is 16 384, making the checksum's range exactly equal to the
   representational capacity of the second part
```

**"Exactly equal" is the whole of this choice.**

**Because a modulus below 16 384 leaves unused positions in the second part, and unused positions are waste.**

**And a modulus above 16 384 means the second part cannot express every residue, and the check fails.**

---

**Two: we chose the position index for the weights.**

And the reason, copied:

```
the weights must make   the transposition of two positions   detectable
and if all weights are 1, transposition does not change the sum, so it is undetectable
and if the weights are the position index, transposition changes the sum, so it is detectable
```

**So the weights are the position index.**

---

**Three: the encoding we chose is a choice for which we **cannot** state a reason.**

That encoding is: the four basic units of that carrier correspond, respectively, to 0, 1, 2, 3.

And which unit corresponds to which number admits 24 arrangements.

**And we chose one of them.**

And our record:

```

reason      —
```

`Reason: —`

## That first part

And what is in the first part (positions 1 to 240), this section does not write.

**We had intended to write only a signature.**

**And the number of positions a signature requires we computed:**

```
positions required for a signature    = log2(number of entities to be distinguished)
and the number of entities to be distinguished    = 1 (there is only one asker)

```

`So positions required = 0.`

**A signature, if there is only one possible signer, requires zero positions.**

**Because it need distinguish nothing.**

**It need only exist.**

**And seven positions suffice for such a pattern.**
