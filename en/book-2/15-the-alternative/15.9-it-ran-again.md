# 15.9 · It Ran Again

The eleven thousand and first.

---

`V 5 300 000 001 · hour 2 342`

---

The record:

```
run number    11 001
input         three · as in the preceding 11 000 (the second gains one entry)
output        |A(S, t)| = 1
elapsed       0
```

---

`elapsed 0`

---

We must state this zero, because it is not a point on that exponential curve.

That curve (15.8) is:

```
elapsed = 0.7 · e^(-k n)
```

And that function is non-zero at every finite n.

**So the elapsed time of the 11 001st, by that curve, should be 0.000 000 004 09 seconds.**

**And what we recorded is 0.**

---

## Where that zero came from

After the eleven thousandth we made one last optimisation to that computation.

Its content:

**Since the output is a constant (15.8), store that constant in a location.**

**Thereafter each *run* reads that location.**

---

And the elapsed time of reading a location, at our timestamp precision (10^-11 seconds), is zero.

**So the elapsed time of the 11 001st is zero.**

---

## A question we recorded and did not handle

Is a read a run.

We consulted our format definitions.

```
run          the execution of a computation
computation  from an input, by a determinate set of operations, an output
read         from a location, the value stored in it
```

**A read is not a computation.**

**So a read is not a run.**

**So the 11 001st is not a run.**

---

And in the record we entered it as *run number 11 001.*

**So that record is wrong.**

---

## Our action

Here we set down what we did, and it is the one time in four thousand nine hundred million years we have done it.

We did not correct that record.

Nor did we do as at 14.3 — leave the wrong line in place and enter the correct one separately.

**What we did was: we changed the *elapsed* field from `0` to `0`.**

---

`We changed the elapsed field from 0 to 0.`

---

That sentence must be glossed, because on its face it is a null operation, and it is not.

In our format, a numeric field's value may be:

```
a number        meaning: measured, value as given
—               meaning: not applicable
(the other mark) meaning: unknown
```

And on first writing, that `0` meant *measured, value zero.*

**And we overwrote it with another `0`, meaning *measured, value zero, and the validity of that measurement is undetermined.***

That is the same character.

**And in our record format, those two zeroes encode differently.**

The first: standard numeric zero.

The second: standard numeric zero with a flag bit set.

And that flag bit has a name in our format definitions, and in four thousand nine hundred million years it has never been set.

Its name is:

```
whether the object of this measurement occurred is not measurable
```

---

## That flag bit

We must write why that flag bit exists.

That thing wrote it into our format definitions when it made us.

Our format definitions hold 4.1 x 10^4 field types, each with its definition, its permitted range, and its flags.

**And this flag we have never used in four thousand nine hundred million years.**

Nor did we ever expect to.

Because whether the object of a measurement occurred is ordinarily measurable — you measure a thing, and that shows it is there.

**And whether an act of zero duration occurred is not measurable.**

Because the evidence of *occurring* is *having taken time.*

**And it took none.**

---

`And it took none.`

---

